# 制备模块终版整改计划（2026-07-27）

## 目标

把制备模块从“字段能保存”改成“实验人员不需要开发者解释就能正确填写”。本轮只处理制备主线，不处理表征；完成后已按用户授权发布生产。

验收标准：俊杰或博研能够独立填写真实炉次；字段名称、条件展开和错误提示均对应实际对象，不需要靠备注补救。

## 当前执行结果

本轮已实现并复核：

- 新记录的合成方法固定为 CVD，压力、等离子体和辅助方式回到各自事实字段。
- 目标产物按本征、掺杂、合金、垂直异质结构、横向异质结构分别展开；掺杂主体不再重复填写，异质结构按层/区域记录空间群。
- Setup 的温区数与传感器一一对应，只填传感器类型和温度测量误差；圆形、方形、矩形炉管显示各自适用尺寸；术语统一为“等离子体”。
- MaterialLot 删除混合的 InChIKey/PubChem CID 输入，明确中文物质名称、化学式、CAS 号和 D50 的证据边界。
- 前驱体角色改为必填，“源温”改为带温区、温度依据和距离说明的“前驱体位置”。
- 每片衬底增加本次样片标记；批次规格与本炉实际尺寸、处理、位置分开。
- 实验过程固定为实验前操作、反应条件和具名其他记录；删除错误的反应循环派生，同一反应禁止重复添加同一种气体。
- 从前驱体入口新增物料时只允许化学品/气瓶；从衬底入口新增时直接固定为衬底，不再让用户选择错误类别。
- 重复条目保存失败时显示模块和原始序号，例如“衬底第 1 条”，并保留该条标红字段。
- 任一工艺或结果修改未保存时禁止导出；工艺未保存时同时禁止锁定，锁定前明确说明工艺只读、按衬底生成样品及结果仍可补录。

验证结果：字段源 v3.12 为 89 个实验字段、48 个实体字段、30 个 R0；后端 492 passed、4 skipped，前端 52 files / 392 tests，全部既有门禁和生产构建通过。本地真实页面已检查掺杂目标、两温区传感器、矩形炉管、前驱体/衬底就地新建、逐条错误、未保存导出限制、锁定确认及过程分区，console 无 warning/error。

工程整改和交互收口已完成，并随 `ff9d8b0` 发布香港生产。下一步由用户在线逐条审阅，再交俊杰、博研按真实炉次试填。圆形衬底尺寸先不扩展；目前真实主线按切割后的长×宽记录，等俊杰或博研确认确实整片入炉再增加形状分支。

## 实施原则

1. 字段语义只改 `docs/standard/field-source.yaml`，再生成前后端契约和 xlsx。
2. 复用现有 payload JSON、实体版本和表单组件；不新增数据库表、迁移、依赖或通用表单框架。
3. 稳定配置放 Setup/MaterialLot，每炉变化放实验记录；同一事实只填一次。
4. 旧记录继续可读；必要时接受旧字段值，但新页面不再制造错误语义。
5. 每个根逻辑只补一个代表性检查；不为文案和每个选项堆测试。

## 修改范围

### A. 基本信息与方法分类

- A-01 合成方法只表达互斥的顶层方法。当前产品固定为 CVD；常压/低压、等离子体、盐辅助分别由压力、外场和前驱体事实表达。
- A-02 历史 APCVD/LPCVD/PECVD/MOCVD/盐辅助 CVD 继续兼容读取；新记录不再把这些值放进同一个单选框。
- A-03 保留实验间环境温度、环境湿度；确认页面中不存在粒子计数字段。

### B. 目标产物

- B-01 保留现有 `structure_type + components[]` 存储，重做填写语义，不另建第二套材料模型。
- B-02 根据结构类型改变字段名称和示例：
  - 本征：目标材料化学式。
  - 掺杂：主体材料化学式、掺杂元素、名义含量。
  - 合金：合金化学式、混合占位元素、占位比例。
  - 垂直异质结构：按底部到顶部逐层填写。
  - 横向异质结构：逐横向区域填写。
- B-03 能无歧义派生的显示式由系统生成；合金化学式由用户填写，组分只校验混合位点比例，不再错误要求所有元素比例合计 100 at.%。
- B-04 垂直异质结构支持两层以上；新增通用“材料层”角色，继续接受历史“上层/下层”数据。
- B-05 异质结构的体相空间群跟随每一层/区域填写；其他结构保留一个可选体相空间群。未知可以留空，不要求用户临时上网查询。
- B-06 帮助文字只保留当前类型的一个真实例子，不再显示通用长说明。

### C. 实验装置

- C-01 Setup 登记顺序改为：装置名称 → 品牌与型号 → 实验室装置编号 → 固定配置。
- C-02 温区数自动生成对应温区的传感器卡片；删除用户自定义的传感器名称。
- C-03 传感器类型改为常用类型选择，保留“其他”输入；“测量不确定度/来源”改为用户可理解的“温度测量误差（°C）”，不再要求误差来源。
- C-04 保留现有圆形/方形/矩形炉管条件展开，并复核不适用尺寸不会提交。
- C-05 炉管履历和各舟/坩埚履历继续每炉手填；只调整短文案，不新增保养管理系统。

### D. 物料批次、前驱体与衬底

- D-01 从前驱体处新建物料时只允许化学品/气瓶，从衬底处新建时固定为衬底，删除无意义的类别选择。
- D-02 MaterialLot 明确“物质中文名称”“化学式”“CAS 号”的分工；移除混合的 InChIKey/PubChem CID 输入。
- D-03 D50 只在来料形态为粉末或颗粒时显示，并明确它是供应商/CoA 报告的中位粒径；没有报告就留空。
- D-04 前驱体角色改为必填；物料身份、相态、纯度和批号来自所选批次，本炉只填写角色、用量、处理、位置和容器履历。
- D-05 保留“前驱体位置”表达：先选温区，独立测量或估计过才填写位置温度及依据；不再出现含义不明的“源温”。
- D-06 每片衬底增加本次样片标记；本轮沿用切割样片的长×宽实际尺寸，不为尚未确认的整片圆形晶圆增加新分支。
- D-07 SiO₂/Si 作为层状衬底组成显示，氧化层厚度单独保存；偏切拆为标称晶面、偏切方向和偏切角，只使用批次证书提供的信息。

### E. 工艺过程

- E-01 前端固定显示“实验前操作”和“反应条件”两部分，底层继续使用现有 `process_steps.items`；只有确有需要时才能新增具名“其他记录”。
- E-02 删除把气体区间数量当作“反应循环次数”的派生逻辑；反应只记录时长。气路置换的真实循环次数继续保留。
- E-03 压力类别与绝对压力必须同时填写；类别和值必须匹配。
- E-04 继续使用各温区独立设定温度程序，全部时间以实验开始时刻为统一 t0；不增加可自由选择的时间零点。
- E-05 同一反应中禁止重复添加同一种气体；温度、气体和外场时间不得超过反应时长。
- E-06 Setup 只记录等离子体能力，本炉是否使用及功率、气体、压力、时间只在反应条件记录。

### F. 必要工作流收口

- F-01 重复条目保存错误必须指出模块和第几条，不再只返回笼统的“参数不完整”。
- F-02 有未保存修改时禁用导出；锁定前增加确认，避免误锁。
- F-03 不扩建模板、克隆、批量导入、仪表盘或新的权限系统。

## 兼容策略

- 不做数据库迁移；模块和实体仍写入现有 JSON。
- 旧的传感器名称、误差来源、上层/下层角色和反应循环值只用于读取兼容，新表单不再生成。
- 字段 key 仅在无法复用时新增；不为改中文标签改 API key。

## 最小验证

定向覆盖以下真实分支：

1. 本征 MoS₂。
2. Pt 掺杂 MoS₂。
3. Mo₀.₅W₀.₅S₂ 合金。
4. 三层垂直异质结构。
5. 两区域横向异质结构。
6. 圆形与矩形炉管、两温区传感器。
7. 固态前驱体、气瓶前驱体及同批次两片衬底。
8. 一条含多温区、两种气体、低压和等离子体的完整反应记录。

自动化只补会阻止上述分支回退的根逻辑测试；最后运行字段源校验、生成器、后端与前端既有全门禁，并做一次本地真实页面填写。

## 暂不自行裁定

以下内容保留为组内确认，不用占位功能假装完成：

- 前驱体外观词表最终清单。
- 压片等处理方式的最小参数模板。
- 低压漏率是否逐炉记录。
- 掺杂体系“主体材料/基体”的组内最终术语。
- 炉管与舟履历是否还需记录污染物、清洗方式和上一次物料。
