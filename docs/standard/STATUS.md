## 4. 已冻结 / 已定的决策（**不要重新 litigate**）

- **记录单元** = 制备实验记录（内部键仍为 `run_code`，不改公共 API）；**样品 = 关联主键**；表征为独立记录、外键指向样品。
- **结果模型** = 不在录入端判成败；砍主观 success/partial/failed 标签，保留 §7『观察到的现象』**客观词表**；**结果留存合规规则**（锁定后无结果→“结果待补”提醒）落实 P1 失败即数据。
- **坐标系全局定死**（上游负/下游正，原点固定，随装置引用冻结）。
- **掺杂/合金/异质结** → `结构类型`（判别器）+ `组成明细 components[]`（权威、复合体系条件必填）；显示串化学式是派生。
- **温度** = 设定 + 实测（删"估算衬底真温"）。
- **§6** = 过程事件 Process Events；事件、是否终止、终止原因、具体说明和处理措施分开表达，每条事件使用稳定 UUID 绑定附件。
- **一等实体**（MaterialLot / 装置 Setup / 表征仪器）= 引用 + `版本号` 锁版快照冻结；实验只引用不重录。
- **R0 最小可复现集**（30 项，按相态、结构类型和记录类型条件化）；字段内约束由 JSON Schema 验证，Setup 快照、温区全覆盖、气瓶身份、过程总时长和跨实体条件在保存/锁定时由服务层补验，共同提供机器证据。**PVD 暂不纳入 v2.0 合规**（占位）。
- **时序** 不进 payload_json（FileAsset + 通道注册 + 派生标量）。
- 已审定术语继续沿用（衬底≠基底、生产批号≠供应商货号、校准≠标定）；实验前气体置换的最终组内称呼仍列 §6 线 B，不提前拍板。
- **v2 单轨后放弃"submit 创建版本快照"语义**（2026-07-11 拍板）：`experiment_versions` 随 v1 拆除，不另建 v2 实验级快照——实体锁版快照+状态流转审计留痕已覆盖；未来有真需求再单独立项。
- **P1.5 冻结范围 = 字段语义层**（字段集合/必填与条件/词表/R0 标记；2026-07-11 拍板）：**UI 呈现属性（如"条件不满足时隐藏 vs 仅红星"）不在冻结范围**，可经单一源管线继续演进（见单轨化计划批6）。
- **锁定语义 = 锁工艺、结果后补**（2026-07-11 拍板，方案甲）：locked 炉次**工艺域**（模块 payload、装置引用、状态元数据）只读，**结果域**（表征记录、实测产物、表征附件）可继续写入；“结果待补”提醒随结果写入自动刷新消除。invalid 炉次一切写路径均拒。落地见单轨化计划收尾批 F2。
- **炉次优先产品重构**（2026-07-16 用户逐项确认，阶段 1–4 已实施并通过 E2E）：炉次为默认入口；状态简化为 draft→locked；衬底自动生成样品；结果一次录入但底层保留分表；全组成员可为 locked 炉次补结果；基础资料就地新增；PVD 暂不开放；增加筛选、审计时间线和 JSON/多表 CSV 导出。**2026-07-22 的后续决策覆盖“中文 canonical 值不迁移”：现改为 ASCII code 存储、中英文本地化显示，旧中文仅作写入兼容别名。**其余决策不变。
- **实验人=炉次创建者**（2026-07-22 用户确认）：新建炉次时由当前登录账号自动填入并全程不可修改；不允许选择或伪造其他成员姓名。后端创建与基本信息更新均强制回写 owner 姓名。
