### 1.2 自查发现的额外硬伤（导师还没点到、但下次一定会被问）

按严重程度排序：

1. **全系统没有任何压力字段**。CVD 的 "C" 是化学气相沉积，常压/低压（APCVD/LPCVD）是最基本的分类变量，对成核密度和形貌影响是定性级别的（Langmuir 2024, doi:10.1021/acs.langmuir.4c03567）。更尴尬的是：**汇报 PPT 第 2 页自己写了"仅记录核心温度、压力等参数……缺乏系统漏率等关键背景信息"——而新系统连压力和漏率字段都没有**。这是"自我审查"会当场翻车的点，必须最先补。
2. **没有降温段建模**。温度程序只有升温/保温节点，无降温方式（随炉冷却/开盖冷却/移炉快速冷却）、开盖温度、降温速率。降温是 2D 生长是否多层/出现杂质相的关键段（典型工艺在 ~580 ℃ 开盖）。
3. **没有反应几何字段**：舟材质/形状、衬底-前驱体距离、衬底朝向（face-up/face-down）、倾角全部缺失；衬底 `position_mm` 与前驱体放置 `position_cm` **单位不一致（mm vs cm）且未定义零点基准**（"相对温区位置"——相对哪里？0 在哪？）。
4. **`boat_contamination_level` / `tube_contamination_level` 字段名叫"程度"，类型却是 boolean**——名实不符，正是"字段逻辑随意、经不起推敲"的实锤。
5. **"最小可复现信息集"宣称无 schema 支撑**：68 个字段全部 nullable，必填只有 7 个且多为结构性字段（items 数组本身）；所有模块 `additionalProperties: true`。换句话说：一条几乎全空的记录也能通过校验——"复现性优先"的宣称无法被证据支撑（这正是导师"自夸 vs 证据"批评的具体化）。
6. **设定值与实测值不区分**：温度程序只有 setpoint，没有实测序列的位置；与创新点③直接冲突（已有 measured-timeseries 设计草案待落地，schema 应先留位）。
7. **气体词表把混合气当原子值**：`gas_label` 含 Ar+H2、H2+CO2 等条目，同时又有 `components[]` 数组可拆分——两套表达并存，机器无法统一解析 H2 比例（H2 比例恰是形貌核心变量）。应只保留纯气体词表 + components 多行。
8. **衬底类型词表维度混杂**：如"蓝宝石单抛C<0001>"把材料+抛光+晶向压进一个枚举值——不可再分原则的反例；且 SiO2/Si 衬底**没有氧化层厚度字段**（285 vs 300 nm 直接决定光学判层）。
9. **盐辅助生长没有建模**：盐类辅助剂（NaCl 等）只能塞进 species 自由文本，无角色、用量比、混合方式字段——而盐辅助是组内主力工艺之一。
10. **表征结果是自由文本**：`characterization.result` 为 text，无实测层数/覆盖率/晶畴尺寸/成核密度等量化字段——"数据可复用"宣称在结果侧失效，AI-ready 无从谈起。
11. **炉管历史/记忆效应无处记录**：石英管 >100 炉后失透放出 SiO 污染生长（Sci. Rep. 2017, doi:10.1038/s41598-017-09811-z），但系统既无炉管编号也无累计炉次。
12. **`furnace_info.model` 与装置实体重复**：装置已强制关联（Setup 快照），炉内又手填 model 字符串——同一事实两处录入，必然漂移。

### 1.3 PPT 优点宣称 vs 证据现状（导师要求的"先自我审查一遍"）

| PPT 宣称 | 证据现状 | 判定 |
|---|---|---|
| 结构化记录（机器可读） | 工艺侧基本成立；**结果侧（表征 result）是自由文本** | 部分成立 |

### 2.2 对标结论（一句话）

国际通行做法 = **实体引用（原材料批号/仪器/衬底为一等实体，实验只引用）＋ 设定/实测显式分离 ＋ SI 存储/习惯单位显示 ＋ 词表挂本体 ID**。本系统的"装置快照冻结"已经踩在正确路线上，缺的是把同样的思想推广到**原材料批号**和**数值来源**。

## 三、隐变量文献证据（"扒隐变量"的弹药）

可复现性问题本身有文献正面承认：

- **STEP/ReChart 专家建议**（Bøggild、Hofmann 等，[arXiv:2409.18994](https://doi.org/10.48550/arXiv.2409.18994)）：明确主张透明记录协议、**失败模式**和原始数据——与本系统"失败实验建档"目标同源，可直接引用作为设计依据。
- **湿度**：TMD 气相合成"难复现、对不受控环境湿度敏感"，水汽与 MX2 生成挥发性 MOx(OH)y（Zhao & Jin, *ACS Mater. Lett.* 2020, [doi:10.1021/acsmaterialslett.9b00415](https://doi.org/10.1021/acsmaterialslett.9b00415)）→ **相对湿度建议升必填**。
- **炉管记忆效应**：老化石英管（>100 炉）失透释放 SiO 污染石墨烯（*Sci. Rep.* 2017, [doi:10.1038/s41598-017-09811-z](https://doi.org/10.1038/s41598-017-09811-z)）→ 炉管编号+累计炉次+上次材料。
- **固源/籽晶法 caveats**：批次/成核剂引起复现性问题（Subramanian et al., *J. Mater. Res.* 2020, [doi:10.1557/jmr.2019.394](https://doi.org/10.1557/jmr.2019.394)）→ 批次实体。
- **盐辅助**：卤盐生成低熔点氧氯化物改变成核（*iScience* 2021, [doi:10.1016/j.isci.2021.103229](https://doi.org/10.1016/j.isci.2021.103229)）→ 盐类辅助剂角色+用量比+混合方式。
- **APCVD vs LPCVD**：扩散受限 vs 反应受限，形貌定性不同（*Langmuir* 2024, [doi:10.1021/acs.langmuir.4c03567](https://doi.org/10.1021/acs.langmuir.4c03567)）→ 压力体系字段。

完整的"参数 | 机理 | 记录方式 | 文献"清单已并入 Excel 评审表"设计依据"列。**每个新增字段都有机理或文献出处——这一列就是对"字段逻辑随意"批评的正面回答。**

## 四、V2 重构方案

### 4.0 "到底"的判据（先立规矩，再改字段）

导师定义：元数据 = 数据已经"到底"、不可再分割，价值在于溯源失败。落成五条可操作判据，之后每个字段过这五关：

1. **数值化/受控**：能量化的必须数值+单位；不能量化的用受控词表，禁止主观形容词；
2. **不可再分**：复合概念拆维度（如"蓝宝石单抛C<0001>"→ 材料/抛光/晶向三个字段）；
3. **可溯源**：凡涉及实物（化学品/衬底/气瓶/仪器），记录的是**批次/实体引用**而非名字；
4. **有依据**：每个字段写得出"为什么记"（机理或文献），写不出的删；
5. **来源明确**：数值要能区分设定值/实测值/估计值。

### 4.1 三个结构性改动（比改字段更重要）

**A. 新增"原材料批号库"一等实体（MaterialLot）** —— 本次重构的核心
- 化学身份层：物质名、CAS 号、分子式（可选 PubChem CID）；
- 商业批次层：供应商、货号、**批号、纯度 %、粒径 µm（或目数）**、形态、开封日期、存储方式、证书附件；
- 衬底批次为子类：+ 材料、**氧化层厚度 nm**、晶向、抛光、尺寸；气瓶批次：+ 纯度等级（5N/4N）。
- 实验中前驱体/衬底/气体**只填批号引用**，纯度粒径等自动带出展示——导师原话"直接把批次号对应的纯度、粒径填进表，样品不天天换、可复用上一次"的精确实现。工程上与已有的"装置快照"同构（引用+冻结），照搬即可。

**B. 装置稳定事实 + 每炉炉管及逐前驱体舟/坩埚履历**
- Setup 只维护可复用的装置稳定事实：装置编号/名称、品牌型号、温区与传感器、炉体方向、炉管材质/截面/尺寸、坐标系、外场能力和装置图；
- `equipment.tube_usage_history` 由用户在每次实验中填写炉管的重置次数和重置后使用序号；每个非气态前驱体的舟/坩埚材质、尺寸与相同履历分别写在该前驱体条目中。两者都不自动累计，也不从历史记录推断或回填；
- 删除 `furnace_program.furnace_info.model` 手填项（从 Setup 引用快照带出）。

**C. 数值来源与设定/实测分离（为创新点③留位）**
- 关键过程量（温度/流量/压力）schema 预留 NOMAD 式四元组位：`set_value/set_time` + `value/time` + `measurement_type`(set/measured/assumed)；当前只填设定值不增加负担，但实测时序（热电偶/MFC 采集）有明确归宿——与待落地的 measured-timeseries 设计衔接。

### 4.2 模块级改动一览（一级标题统一中文）

| V1 模块 | V2 模块（中文） | 主要变化 |
|---|---|---|
| basic_info | **基本信息** | 实验开始时间(datetime)置首；experiment_type→合成方法(词表+CHMO ID)；material_system→目标产物；layer_count 拆出（目标层数留此/实测层数去表征）；新增实验结束时间 |
| environment | **实验环境** | 删 sample_env 主观枚举；温湿度升必填；"室内温/湿度"更名"环境温/湿度"(JJF 1101)；悬浮粒子浓度提案经 2026-07-24 走查删除 |
| precheck | **系统预检查** | 新增漏率/保压测试(数值优先)；炉管/舟使用、污染与清洁履历由用户按每炉实际情况填写，不自动推算 |
| precursors | **前驱体** | 批号引用替代 brand+batch_no；新增角色(金属源/硫属源/盐类辅助剂/掺杂源)、混合方式、研磨、装载舟(石英舟/陶瓷舟)、称装后等待时间 |

| furnace_program | **炉温程序** | 温度节点保留；**新增降温段**(方式词表/开盖温度/降温速率)；实测曲线预留位；删手填炉型 |
| gas_program | **气体与压力程序** | **新增压力体系(APCVD/LPCVD)、工作压力、本底压力**；"洗炉"更名"吹扫"(规范术语 purge)；gas_label 删混合气条目、components 成唯一表达；stage 词表化；气体纯度从气瓶批号带出 |
| process_observation | **过程观察** | 异常事件加时间戳（创新点③④）；附件引用 |
| characterization | **样品表征** | 新增仪器引用、测试参数(物镜/功率/积分时间)；**结构化结果：实测层数/覆盖率%/晶畴尺寸µm/成核密度**；原文本降为补充 |
| result_summary | **结果分析** | 失败模式词表扩充并配成因映射；量化指标自动汇总自表征 |
| （实体）Setup/Methods | **装置与方法** | 改中文名；扩充见 4.1B |
| （实体）样品管理 | **样品记录** | 改名 |

### 4.3 必填分级（让"最小可复现集"可被证明）

- **R0 提交必填**＝最小可复现集（开始时间、操作人、合成方法、目标产物、前驱体批号+质量、衬底批号+位置+朝向、温度程序、压力体系、气体程序、降温方式、质量标签）；不填不能提交；
- **R1 鼓励填**：影响复现的隐变量（湿度、间隔时间、几何细节……），提交时黄色警告；
- **R2 可选**：锦上添花。
- 同时收紧 `additionalProperties`，模块 schema 写明 required —— 之后"最小信息集"这条优点才有 schema 证据。
