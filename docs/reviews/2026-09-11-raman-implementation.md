# Raman 整改实施记录 · 2026-09-11

按用户“开始修改”的授权实施[逐项审查](./2026-09-10-raman-field-review.md)。本地契约更新为 **v4.0-alpha.46**；香港生产仍为 alpha.43，本轮未部署。此前 OM alpha.45 和其他前端整改保留，无新增数据库迁移或依赖。

## 设备登记与采集

- 复用 OM 的目录编辑、配置选择和数值校验，增加 `capabilities[].configuration.raman`：激光、物镜或探头、光谱配置。光谱配置引用适用激光，名称在各自目录中唯一。
- 激光登记波长和功率设置单位；显微物镜登记倍率、NA、介质，三项必填，探头不要求物镜参数。干式 NA 必须小于 1，不能凭倍率生成 NA。
- 光谱配置保存光栅、光谱探测器、收集几何、滤光配置，以及适用的狭缝、共焦、增益、偏振、累积方式、低频能力和校准记录。管理员明确哪些参数可在采集时调整。
- 表征选择所用配置，固定参数带入。后端按所选仪器版本复核；修改仪器目录或补登记校准，不改变已保存记录。
- 有目录的 Raman 仪器要求采集形式、功率设置及单位、积分时间、累积次数和位移范围完整；序列中明确变化的参数除外。无目录的历史仪器与外部资料继续允许人工补录和缺项，未对旧记录追溯新增必填项。
- `power_setting` 与 `power_setting_unit` 保存仪器设置，`sample_power_mW` 另存样品处功率。百分比与 mW 不换算；仪器数值设置需为正数，百分比不得超过 100。修改单位会清除旧设置值，应用单位不匹配的功率预设会被拒绝。
- 温度条件区分“室温、未控温”和“记录温度”；有数值时填写来源，存储为 K，没有自动填入室温数值。环境采用短选项，气氛、液体和其他环境需具名。当前界面温度输入仍为 K，没有额外增加单位换算控件。

## 预设与切换

- Raman 预设仅保存功率设置、积分时间、累积次数、范围、适用狭缝、共焦及增益等采集设置。样品处实测功率、样品处理、备注、环境实测值和峰结果不进入预设。
- 应用预设只覆盖相应采集参数，保留峰、观察说明、来源和文件；所选设备的固定值不能被预设覆盖。
- 更换仪器或硬件配置时清理原设备设置，保留样品说明、环境等独立信息及已填结果。对设备的具体引用仍需重新选择，不能把旧 NA、光栅或功率带到另一配置。
- 历史 `low_frequency_raman` 仪器可在 Raman 入口使用，其目录和预设按同一路径读取。低频能力随配置保存，本次采集范围独立记录。

## 扫描、偏振和峰结果

- 采集形式为单点光谱、空间扫描、时间或参数序列。扫描须选择本次原始数据文件 `scan_file_id` 并说明轴、单位和参数列；参数序列另列 `variable_conditions`。
- 变化参数不再重复保存一个标量。前后端同时检查声明、适用条件和原始文件引用；设备固定参数不能被声明成可变化设置。这里只建立数据文件与参数的关联，不宣称已解析或核对文件中的每个数值。
- 平行、正交检偏只适用于线偏振入射；自定检偏需要角度。填写或扫描偏振角时需有参照，规则通过字段源 `requires` 同步到前后端及契约。
- 峰位不得超出已记录的 Raman 位移范围。扫描、序列中的峰需要光谱位置或聚合范围；新表单填写峰宽、峰高或面积时需给出提取及基线处理依据，可明确记录未扣基线。
- 峰高、峰面积填写时才选择强度单位，Raman 不再默认 a.u.。原始及处理后文件可分别记录 `file_intensity_units`；有已知来源单位时，峰强度单位必须一致。合法换算通过相应处理后文件及处理说明表达。
- 原始文件、处理后文件和说明性附件的现有分类、来源校验及删除保护保留。当前载体同时在 Raman 表单显示，测试人与录入者分开记录，文案精简为“测试人”“备注”等。

## 校准、详情与导出

- 设备配置可以登记位移及相对强度校准记录，其内容随选定版本和条件保存。
- 生命周期校准自动匹配需注明仪器版本以及适用配置。`details_json.instrument_version` 对应所选版本；`details_json.configuration` 至少包含激光与光谱配置，功率校准则包含激光与物镜。提供的其他配置引用也必须匹配。
- 校准量支持 `raman_shift`、`relative_intensity`、`laser_power`；英文空格形式按相同含义读取。按量保存测量前最近的适用记录，未注明适用范围的整机事件不再被断言为本次 Raman 有效校准。
- 公共“最近校准或维护日期”仍保留原有管理含义，不作为本次光谱校准证明；本轮没有重做全仪器的维护管理页面。
- 详情和科学导出包含实际条件、所选目录、扫描文件、变动参数及逐文件单位，历史仪器版本和校准快照保持不变。

## 交换契约

标准 JSON Schema 无法单独比较两个任意数值字段。现发布范围对象的 `x-cvd-ordered` 扩展，明确要求第二个端点大于第一个；前端生成的 AJV 校验器和后端 `app.core.scientific_json_schema.ScientificJSONValidator` 均执行该规则，Pydantic 原有范围校验保留。

外部消费方如仅使用普通 Draft 2020-12 验证器，会忽略此扩展，仍须额外检查范围顺序。不能将这种标准能力边界描述为普通 JSON Schema 已自动支持跨字段比较。仪器外键、配置适用性和文件归属继续由服务层检查。

## 保留的边界

厂商原生光谱文件的参数、扫描轴和采集时间自动提取仍需组内真实文件样例，未实现通用解析。当前可上传保留原文件，范围和可变参数由用户填写或引用文件说明；不按文件名推测采集设置。

Raman 字段源现有 41 个条件定义，其中 3 个为历史字段；其余包含设备登记项、条件展开项和采集项，不是要求每次手填 38 个字段。实验总表仍为 126 项、实体 67 项、R0 标记 26 项。
