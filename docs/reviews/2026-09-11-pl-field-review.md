## 2. 现状及常规填写流程

当前仅 `excitation_wavelength_nm` 是 PL 条件必填项。常用区为激发波长、功率及其单位、单次采集时间、累积次数；物镜、NA、光栅、光谱范围及采集形式在“更多条件”。三个处理字段在结果区。因条件展开，34 项不会同时显示。

建议常规显微 PL 使用如下顺序：

**样品 → 仪器及版本 → 激发光源 → 物镜 → 光谱配置 → 功率设置 → 积分时间、累积次数、发射范围 → 原始文件。**

测试时间和测试人沿用公共信息；温控、特殊环境、脉冲、偏振、空间扫描和参数序列按使用情况展开。设备只有一个可用选项时可带入，但不能从“没有填写”推断实际采用了某种模式。

- 组内新建显微设备：物镜名称、倍率、NA、介质登记完整，表征选择后只读带入。NA 不继续作为本次表征里容易漏填的选填文本。干镜和浸液物镜分别校验，不能把所有 NA 一律限制为 ≤1。
- 新采集：功率设置、积分时间、累积次数及范围应有记录，优先来自所选配置、常用采集预设或可信文件；避免增加一组必填项后仍要求每次手写。
- 样品处实测功率：有测量时另行填写，不能因为记录必填而要求所有人临时增加一次功率计实验。
- 参数序列：恒定条件填一次，变化参数引用文件中的逐谱值；不能用一个温度或功率代表整个序列。
- 历史和外部资料：允许保留缺项，不追溯补造数值。未知值在详情中表示为未记录，不要求每个缺项单独写理由。

这里的常规入口首先对应 **PL 发射光谱**。脉冲激发也可以采集时间积分的发射光谱。“每隔数秒记录一条光谱”和“激发后纳秒尺度的发光衰减”应明确区分。当前模型没有 TRPL 所需的时间通道和寿命结果，也不完整支持扫描激发波长的 PLE；不应仅凭 `pulsed` 或 `series` 宣称支持。特殊数据可保留原文件与说明，专门的结构化录入应按真实使用需求另行完善。

## 3. 仪器配置

当前 PL 的固定配置仍可写自由文本，结构化部分只有整套通用预设；没有独立的 PL 激发光源、物镜、光谱配置目录。后端也只允许 OM/Raman 使用 `instrument_configuration`。

| 配置内容 | 建议登记 | 表征时填写 |
|---|---|---|
| 仪器身份 | 编号；厂商、型号、位置等一次登记，沿用版本 | 选择仪器及版本 |
| 激发光源 | 可用光源名称、波长、连续/脉冲输出、功率控制形式；可调谐光源登记范围与可调项 | 固定波长选择后带入；可调项按本次设置填写。激光、LED、灯源不得都强行称“激光” |
| 物镜或收集组件 | 显微物镜名称/型号、倍率、NA、介质；宏观样品架、探头等另记对应组件 | 选择后带入；非显微设备不要求虚构物镜参数 |
| 光谱配置 | 光栅名称/规格、探测器、滤光组件、收集光路、适用光源及可用波段 | 选择支持的组合。相同刻线密度但不同闪耀波长或探测器的配置须可区分 |
| 狭缝、增益、共焦设置 | 固定值登记；可调项声明为可调，采用设备显示的量与单位 | 只显示本设备可调项。显微设备的共焦孔径/收集光纤会限制采样范围时，保留其配置；不把它当作物镜 NA 或光斑直径 |
| 脉冲设置 | 固定脉宽、重复频率随光源登记；可调值列入采集设置 | 使用脉冲光源时才显示；支持 fs/ps/ns 和 Hz/kHz/MHz 方便输入，保存统一单位 |
| 偏振组件 | 入射偏振、检测偏振通道、波片配置与角度参考；按已安装附件登记 | 普通固定状态带入，只有偏振实验才选择/调整 |
| 校准和校正曲线 | 波长校准、发射响应曲线及功率校准分别保留适用版本/光源/光路/探测器/波段等已有依据 | 本次关联适用记录；不自动复用 Raman 位移校准或另一光路的响应曲线 |
| 常用采集预设 | 仅保存可重复使用的采集设置 | 主动应用，只覆盖对应设置；保留峰、观察、样品处理、环境实测值和文件来源 |

复用现有目录编辑器、版本快照和采集预设机制即可。无需另建 PL 仪器台账，也无需枚举所有光源×物镜×光栅的笛卡尔积。共用硬件的 Raman/PL 可以复用已经登记的规格，但本次配置及方法适用性仍分别核对。

## 4. 34 个条件字段逐项结论

表中的必填建议面向配置完整的组内新设备和新采集，不是对历史资料加硬性补录要求。

| # | 当前字段 | 设计判断与理由 | 建议 |
|---|---|---|---|
| 1 | 激发波长 `excitation_wavelength_nm` | 影响激发响应；常规 PL 必需。每次手输不如选光源方便 | 保留，固定光源带入；可调谐光源填写本次值，必须 >0。无需额外要求用户重复填写激发能量 |
| 2 | 激光功率 `excitation_power_value` | 功率影响信号和样品状态，但当前只能保存一种读数 | 改为仪器“功率设置”与选填“样品处功率”，允许同时记录；脉冲光源的平均功率在相应字段明确 |
| 3 | 功率单位 `excitation_power_basis` | “样品处 mW / 仪器 %”区分了位置，却漏掉软件 mW、其他档位 | 设置单位/档位来自设备；样品处测值独立保存。% 不换算成 mW，修改单位不得沿用旧数值 |
| 4 | 单次采集时间 `integration_time_s` | 对计数、噪声和不同谱之间的比较重要，使用者熟悉 | 简化为“积分时间（s）”。阵列采集按每次曝光，扫描单色仪按每波长点；不能混为全谱耗时 |
| 5 | 光谱范围 `spectral_range_nm` | 决定本次覆盖的发射波段；当前仅 nm，峰却支持 nm/eV，且允许下限 0 | 名称“发射范围”，常用区；输入可选 nm/eV、端点均 >0，记录轴和单位。若继续保存 nm，转换时保持上下限顺序；不能把名义探测范围当本次范围 |
| 6 | 测量温度 `temperature_K` | 影响峰位、峰宽和强度；普通用户通常没有样品测点温度 | “室温、未控温”与“记录温度”分开；后者要求数值及来源。支持 ℃/K 输入，保存统一 K，不自动填 298 K |
| 7 | 物镜规格 `objective` | `100×，NA 0.9` 文本与独立 NA 可能冲突 | 改为物镜选择；名称、倍率、NA 和介质来自同一登记项 |
| 8 | 光谱累积次数 `accumulations` | 影响信噪比与强度解释；并非扫描点数或重复样品数 | 简化“累积次数”，正整数，常用区；可应用预设，不暗填 1 |
| 9 | 物镜数值孔径 `objective_na` | 倍率不能推出 NA；当前只要求 >0，NA=10 也通过 | 显微物镜登记必填，选物镜带入；不保留第二个可独立修改的 NA |
| 10 | 实际光栅刻线密度 `grating_lines_per_mm` | 影响色散，单一数字不能唯一标识光栅及波段效率 | 改选“光栅/光谱配置”，显示登记规格；不要求手填实测分辨率 |
| 11 | 入口狭缝宽度 `slit_width_um` | 有明确作用，但不是所有 PL 设备用 μm 设置 | 固定值登记，可调值按软件填写。软件若提供“光谱带宽（nm）”，记录该量；若有激发与发射两套单色仪，分清两侧，不直接换算成 μm |
| 12 | 实际滤光配置 `filter_configuration` | 阻断激发光、选通发射及抑制杂散光会改变有效波段 | 简化“滤光配置”，设备登记后选择；区分激发端衰减与收集端滤光，避免全塞进功率字段 |
| 13 | 实际探测器/相机 `detector` | 光谱探测器影响响应；定位相机与其用途不同 | 名称“光谱探测器”，设备登记后带入 |
| 14 | 探测器增益及单位/档位 `detector_gain` | 增益影响信号表示，但有些设备固定或由软件管理 | 简化“增益”，仅可调时显示，保持设备单位/档位；不全局规定 dB |
| 15 | 光学收集几何 `collection_geometry` | “反射/背散射、透射”借用了 Raman/OM 术语，未清楚说明发光的收集方向 | 设备登记同侧、对侧、90°或具名光路；方向相对激发光说明。PL 发射不因同侧收集就变成散射信号 |
| 16 | 入射偏振状态 `incident_polarization_state` | 线、圆、椭圆、非偏振有物理区别，但单个“圆偏振”不足以表明激发通道 | 普通固定状态登记；偏振 PL 才记录具体状态及圆偏振通道。未安装起偏器不等于非偏振，未知可留空 |
| 17 | 检偏方式 `analyzer_mode` | “未加、固定、随动平行、随动交叉”混合了附件、角度关系和运动方式 | 按设备区分不检偏、线偏振检测和圆偏振通道。线偏振才使用平行/正交；圆偏振使用有明确定义的同/反手性通道，不能套用 Raman 的“圆偏振不能交叉”规则 |
| 18 | 入射偏振角 `incident_polarization_angle_deg` | 线偏振方向有意义，但当前可以无参照保存 | 固定角度带入，可调时填写；角度需有零点与正方向。样品晶轴参照不从设备自动推定 |
| 19 | 检偏器角度 `analyzer_angle_deg` | 当前 fixed 模式下可缺角度，其他模式又隐藏 | 自定线偏振角度时必填；选明确通道时从配置带入，不重复填一组矛盾数值 |
| 20 | 偏振角参照/正方向 `polarization_reference` | 有角度而无参照不能复用；对普通非偏振采集没有独立填写价值 | 简化“角度参照”，有角度时要求；圆偏振手性需另在通道定义中明确传播/观察方向，不能拿这个角度文本代替检测通道 |
| 21 | 其他收集几何 `collection_geometry_other` | 选“其他”后要求具名正确 | 保留，通常随设备登记，不逐次重写 |
| 22 | 采集形式 `acquisition_kind` | “单次采集”容易与累积次数冲突；“时间序列”也容易和 TRPL 混淆 | 改“单点光谱 / 空间扫描 / 时间或参数序列”。单点可多次累积，时间序列指逐谱采集；不含寿命衰减的隐含承诺 |
| 23 | 扫描轴/步距/逐点参数来源 `scan_coordinates` | 文本提到了文件，但没有实际文件关联，mapping/series 可留空 | 简化“扫描参数”，选择原始扫描文件，记录轴/单位/列名和变化参数；变化值保留在文件，不要求手抄每一点 |
| 24 | 测量环境 `measurement_environment` | 对 PL 有作用；自由文本不便统计，容易与温度混写 | 空气/真空/气体/液体/其他，按需补名称；气体、液体、其他需具名。压力或气氛是研究变量时记录对应值或文件，不让所有空气测量填压力 |
| 25 | 温度口径 `temperature_basis` | 环境、样品台设定和样品测值必须区分，但当前不与温度成对校验 | 改“温度来源”，记录数值温度时出现；不把样品台设定当测点实测 |
| 26 | 强度处理口径 `intensity_processing` | 原始计数、计数率、归一化的互斥选项不能表达完整处理；同一测量可有多个处理层级 | 移到对应文件的单位与处理记录。counts、counts/s、a.u. 根据文件或明确选择；a.u. 不自动等于归一化 |
| 27 | 光谱累积处理 `accumulation_method` | 求和/平均描述合并方法，“分别保存”描述文件组织，不是同类选项 | 只保留求和/平均；固定方式随配置带入，单次累积无须额外选择。逐次谱保存在文件，保留相应来源 |
| 28 | 光谱响应校正 `response_correction` | PL 谱形和相对强度相关，保留有意义；当前整条记录的选择无法区分 raw/processed | 绑定具体文件，保留已应用/未应用及未记录状态；不是每次必填一页校准表，也不能因预设勾选就认定当前文件已校正 |
| 29 | 响应校正配置/报告 `response_correction_source` | “已应用”目前不要求来源，可留空 | 已应用时引用适用曲线/仪器输出说明/报告；来源已在设备或文件中则引用，不重复抄。只确认仪器进行了校正但没有曲线时如实保留已有依据 |
| 30 | 激光输出 `excitation_mode` | 连续/脉冲决定功率及激发过程解释；与单点/扫描不是同一层级 | 改“激发方式”，固定光源带入。不能默认所有 PL 都是激光，也不能将“脉冲”直接等同 TRPL |
| 31 | 脉冲宽度 `pulse_width_fs` | 脉冲激发的重要条件；fs 单位不方便记录数十 ps/ns 的设备 | 脉冲光源登记固定值；可调时填写，按设备显示可选 fs/ps/ns。不将厂家标称值包装成样品处实测脉宽 |
| 32 | 重复频率 `repetition_rate_MHz` | 平均功率相同、重复频率不同并不意味着同样的每脉冲激发 | 脉冲时记录，固定值带入；支持 Hz/kHz/MHz。没有脉形及作用面积时不自动计算峰值功率或激发密度 |
| 33 | 表征前制样/处理记录 `sample_preparation` | 处理和载体可影响结果，但应属于样品或本次测量 | 改“表征前处理”，选填，引用已有记录；不进入设备预设 |
| 34 | 采集条件来源/缺项说明 `acquisition_note` | 将来源、补充说明和缺项解释合在一起，造成额外填写负担 | 改“备注”，选填，无需常驻占位。文件和配置已说明的来源不重复填写 |

补充边界：若组内确有扫描单色仪，波长步长及每点积分时间是使用者熟悉的设置，应由该设备展开；阵列探测器整段采集不应额外要求逐点扫描步长。是否新增专用字段应依据本组仪器，而不是对所有 PL 用户开放一整套通用荧光仪参数。

## 5. PL 特有的结果、单位和文件问题

### 5.1 峰位、峰宽与面积

现有新录入项是普通峰位、FWHM、峰高、面积和观察。历史的 A/B 激子归属、积分强度单值、`pl_peak_fwhm` 仍为 legacy，不恢复为默认必填结果，也不直接将 PL 峰等同带隙、层数或材料身份。

| 结果 | 当前行为 | 建议 |
|---|---|---|
| 峰位 | 支持 nm/eV、要求正数，但不核对采集范围 | 保留两种单位，依据同一来源光谱核对范围；转换范围用于检查时应考虑端点次序与记录精度 |
| FWHM | 选填正数，单位跟随峰位；因此 eV 峰位的峰宽也输入 eV，不能把旧字段的 meV 当当前单位 | 保留。能量轴上可提供 meV 便捷输入，正确换算回保存单位，例如 40 meV = 0.040 eV |
| 峰高 | 非负，缺少提取/基线要求 | 保留选填，单位跟随来源文件；填写时记录已有取值/拟合与基线依据 |
| 峰面积 | 当前显示“强度单位 × 峰位单位” | 仅适用于按该横轴定义的积分；注明拟合或积分范围。不能将通道计数求和和按 nm/eV 积分混写 |
| 强度单位 | PL 草稿仍默认 a.u.；只填峰位时也显示 | 填峰高/面积时再出现，优先读取来源文件，否则明确选择；不自动补 a.u. |
| 来源文件 | 可用 raw/processed 证据，supporting 不可作峰来源；单一证据自动关联 | 逻辑保留；文案“对应原始光谱”改“来源光谱”，与允许处理后文件一致 |
| 文件内位置 | 有输入，但 mapping/series 不要求 | 多谱文件有结果时要求谱号、坐标、时间或聚合范围；单条谱无需额外填写 |
| 提取和基线 | 已有简短文本，PL 不要求 | 有 FWHM、峰高或面积时应能追溯定义，复用文件处理说明，允许明确未扣基线；不新增完整分析软件登记页 |
| 未检出 | “未检出可分辨峰”需引用文件 | 保留；不等同零发光或样品没有该材料，只限对应光谱与检测条件 |

nm 与 eV 间的峰位坐标可用 `E = hc/λ` 表示，但 **不能把 nm 的峰宽直接代入同一公式当作 eV 峰宽**。如果原数据定义为每单位波长的谱密度，转换为每单位能量的谱密度还需 `I_E = I_λ |dλ/dE|`；这是变量变换关系。轴变换后线形可能改变，应保留原文件及处理依据，不自动改写峰高、面积或拟合宽度。当前切换峰位单位会确认并清空峰参数，没有偷偷做错误换算，这一点应保留或改成明确的转换流程。上列文献及勘误提供此问题的参考，不推定所有仪器导出的 counts 都已经是谱密度。

### 5.2 文件与响应校正

- 原始光谱仍必填，保留仪器原生文件和包含横轴/强度数据的导出。上传接口目前未解析 PL 光谱轴、激发功率、积分时间或校正标记；上传成功不等于元数据已自动提取。
- 处理后光谱必须关联本次原始文件并有处理说明；报告和截图可作为说明性附件。既有角色及来源关联机制保留。
- 同一测量可能同时有未校正原始谱、校正后谱和归一化谱。响应校正状态应跟随文件，不能由一个测量级选项覆盖三份文件。
- 原始文件可以含仪器在线完成的校正。应记录其处理状态，不能武断要求用户提供仪器根本不输出的“完全未处理”数据。
- 原始 counts 与结果 counts/s 不一定矛盾，可能有合法换算；问题是当前缺少单位与处理来源的关联。应通过处理后文件和说明表达，而不是简单禁止不同单位。
- 校正曲线应适用于所用光谱配置及波段，已应用响应校正也不等于获得绝对量子产率。不新增默认的 PLQY 或寿命字段。

### 5.3 偏振 PL 不能照抄 Raman

线偏振的平行/正交可以描述两个方向的关系；圆偏振 PL 的同手性/反手性检测也是有效实验，常用于二维材料。现在既缺入射圆偏振通道，也缺检测手性和传播方向约定，单个“圆偏振 + 交叉”无法清楚表达是哪一对通道。建议只对装有偏振附件的配置开放这些选项，并保存已定义的通道。无需让普通 PL 用户填写 Stokes 向量或全部波片角度。

## 6. 公共信息、校准和导出

| 项目 | 判断和建议 |
|---|---|
| 样品、测试时间、测试人 | 已关联样品；测试时间不再默认成打开页面时间；测试人与录入者分开，保留 |

## 9. 文案

保留短标签：激发光源、物镜、光谱配置、功率设置、样品处功率、积分时间、累积次数、发射范围、测试温度、温度来源、扫描参数、来源光谱、表征前处理、备注。

仅在会影响如何填写时保留短提示，例如脉冲模式下的“填写平均功率”、扫描来源中的“轴名称、单位和列名”。当前 PL 备注占位已不是早期的“不猜填默认值”，但仍使用“采集条件来源/缺项说明”的标题；建议改为“备注”，去掉补写缺项理由的要求。数据准确性通过空值、来源、单位和配置约束实现，不依靠反复提醒用户。
