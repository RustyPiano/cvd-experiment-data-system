# OM 字段与配置复核 · 2026-09-10

后续：用户已授权实施，alpha.45本地结果见[实施记录](./2026-09-10-om-implementation.md)。下文保留alpha.44审查时的事实与建议，不表示这些问题仍全部存在。

本轮为审查建议，未修改业务代码、字段必填规则或生产数据。审查对象为工作树 alpha.44：包含已发布 alpha.43 的 OM 字段和未发布的仪器配置预设。采用用户提出的标准：影响明显、使用者能理解、参数容易取得；固定信息一次登记，本次设置随采集记录。不能把“减少重复填写”等同于“关键参数可缺省”。

已逐项核对35个现行OM条件字段、3个历史条件字段、仪器登记和预设、公共信息、文件分类、保存校验、详情及科学导出。没有实际机型清单或采集软件参数页，因此厂商资料仅证明参数的科学意义和可能控制方式，不证明组内设备支持全部选项。

**结论**

当前实现尚不适合冻结。应保留NA、曝光、增益、白平衡、照明和图像尺度这些重要信息，并把设备信息、实际设置、图像属性和样品处理放在各自的位置。取消对位深、黑电平等项目的普遍手填要求；不把所有内容移入设备表单后继续要求人工录入。

NA应在组内物镜登记时与倍率、适用介质一起必填，表征选择物镜后带入。历史及外部资料缺项需允许保留，不能自动补值。此前将NA笼统设为选填的建议不成立。此前建议常规只保留白平衡模式也过度简化：软件若直接显示白平衡色温或通道增益，应记录相应设置，不能只留“手动”二字。

**1. 证据及其适用范围**

- 物镜倍率和NA是不同信息。显微成像元数据分层规范将物镜厂商、型号、倍率、NA列为解释和复现所需信息；这支持完整登记物镜，不能据此要求每次重新手填全部参数。[原始规范论文](https://pmc.ncbi.nlm.nih.gov/articles/PMC9271325/)
- 物镜、照明和图像对比机制应分别表达。明场、暗场、相衬、DIC是不同的对比机制，反射/透射是光路维度。[Nikon：图像对比](https://www.microscopyu.com/techniques/dic/specimen-contrast-in-optical-microscopy)
- 曝光自动控制分一次调整和持续调整；停止自动调整后可继续使用之前的值。“自动”不等于没有曝光数值。[Basler：自动曝光](https://docs.baslerweb.com/exposure-auto)
- 增益可以自动调整，且相机输出可能包含模拟或数字增益；不应把一个设备档位自动换算为另一设备的dB。[Basler：增益](https://docs.baslerweb.com/gain)、[自动增益](https://docs.baslerweb.com/gain-auto)
- 自动白平衡关闭后仍可应用手动通道增益，因此不能把设备界面的自动白平衡Off直接翻译成“未进行白平衡”。[Basler：白平衡](https://docs.baslerweb.com/balance-white)
- 图像长度测量需要适用的尺度校准，倍率本身不能替代每像素的样品长度；校准图和样品图需要相容的成像及采样设置。[Nikon：显微测长](https://www.microscopyu.com/microscopy-basics/linear-measurements-micrometry)
- OME分别记录PhysicalSizeX/Y、SizeX/Y、SignificantBits以及探测器的Gain/Offset/Binning。不能把RGB总位数当成每通道有效位深，也不能把裁剪、重采样和像素合并混为同一操作。[OME字段模型](https://www.openmicroscopy.org/Schemas/Documentation/Generated/OME-2016-06/ome.indexList.html)
- 对二维材料，样品当前载体与照明波段不能遗漏。例如石墨烯在SiO₂/Si上的可见度受氧化层厚度与照明波长影响；该结果不能直接推广为所有材料的定量规律，但说明载体记录的重要性。[Blake等：Making graphene visible](https://arxiv.org/abs/0705.0259)

**2. 设备登记建议**

“固定”是指配置身份或标称规格稳定，不表示物镜、滤光片等在每次实验中都不更换。

| 内容 | 建议登记方式 | 后续使用 |
|---|---|---|
| 仪器编号 | 必填，已有身份机制保留 | 选择仪器，版本后台留存；补录可选对应历史版本 |
| 厂商、型号 | 推荐按铭牌一次登记；自制/改装设备采用实际可识别名称 | 不在每条OM中重新输入 |
| 序列号、机构持久标识 | 管理选填，不能代替仪器编号，也非每次成像条件 | 无则不显示重复空字段 |
| 实验室、位置 | 管理选填 | 不要求每次填写 |
| 物镜列表 | 倍率、标称NA、适用介质必填；型号/标识区分同倍率不同物镜 | 如“50× · NA 0.80 · 干式”，选择后带入；不能仅凭50×匹配物镜 |
| 相机列表 | 可识别型号或名称，支持的彩色/单色采集模式 | 相机固定时带入；多台时选择实际使用的一台 |
| 光学配置 | 登记实际支持的光路和成像方式组合，如反射明场 | 界面可一次选择组合，保存仍区分光路和成像方式；有一种配置时可带入 |
| 光源及控制 | 光源身份、亮度单位/档位、是否固定或可调整 | 单一固定光源带入；可变亮度记录本次读数 |
| 成像尺度配置 | 记录经校准的μm/px及其适用的物镜、相机和成像/采样配置、校准依据 | 同一物镜更换相机、转接倍率、变倍位置或采样设置后不能无条件复用 |
| 特殊附件 | 仅实际具备时登记滤光片、偏振或可调光阑等 | 实际使用时才显示相应控制 |
| 常用采集预设 | 仅含可重复使用的采集设置；与物镜/相机/光学配置关联 | 不能包含本次样品处理、文件位置、观察结果、缺项说明 |
| 校准/维护 | 二者分开理解；常规填写不要求反复上传证明 | 整机最近维护日期不能证明某物镜/相机配置的尺度已校准 |

设备只保存支持的功能和已知配置。没有增益控制的设备不出现增益输入；可自动增益但不显示数值，不能登记成“固定增益”。NA大于1对浸液物镜不一定错误，不能设置所有物镜统一上限1；应结合介质和规格校验。变倍、可调NA设备按实际配置另行支持，不能直接套用固定物镜规则。

**3. 35个现行条件字段逐项去留**

“应记录”表示影响明显，应优先从文件、选定设备配置或采集软件获得；不等于对所有历史、外部或不提供该读数的设备强行设非空。“自动附带”是调整建议，目前尚未完成厂商文件元数据导入。

| # | 当前字段（key） | 重要性与取得方式 | 建议位置及规则 |
|---|---|---|---|
| 1 | 记录方式 observation_mode | 决定是否存在相机与图像条件，用户容易判断 | 每次必选：目视观察/数字图像。目视记录需观察说明，数字图像需采集文件；设备信息仍尽量关联 |
| 2 | 物镜规格 objective | 影响明显，可直接选择已登记物镜 | 每次选物镜；倍率独立登记，文本改为型号/标识，不再示例填写第二份NA |
| 3 | 物镜NA objective_na | 影响分辨能力和集光，镜身/规格通常可取得 | 物镜登记必填，表征只读带入。不得自动从倍率推断 |
| 4 | 浸没介质 objective_immersion | 关系到物镜适用条件，一次查明即可 | 物镜登记干式/油浸/水浸/其他；表征带入，实际不同需对应配置 |
| 5 | 光路 optical_path | 反射与透射不同，用户通常熟悉 | 按设备光学配置选择或带入，不靠衬底自动推断 |
| 6 | 成像方式 contrast_method | 明场/暗场/DIC/相衬/荧光/其他改变对比机制 | 只提供该仪器已支持的组合；常规入口不预先展开所有技术 |
| 7 | 其他成像方式 contrast_method_other | 避免“其他”无具体含义 | 仅选择其他时必填，优先在设备配置里具名一次 |
| 8 | 相机 detector | 影响响应，用户知道实际相机或可查型号 | 数字图像选择/带入；避免每次自由文本重录 |
| 9 | 曝光时间 exposure_time_ms | 影响明显，采集软件一般提供 | 数字图像应记录，输入ms或由文件读取；预设值不一定是自动曝光后的实际值 |
| 10 | 曝光模式 exposure_mode | 说明值如何取得，采集软件常有控制 | 按设备界面表达固定/自动；设备可识别时再区分一次自动和连续自动，不强迫追忆软件已不显示的历史操作 |
| 11 | 相机增益 detector_gain | 影响亮度、噪声和可比性 | 数字图像应记录本次可读值及设备单位；固定值随配置，自动值随文件。自动增益功能实际存在时才增加相应控制 |
| 12 | 图像颜色类型 image_color_mode | 决定白平衡适用性 | 名称改为采集颜色模式：彩色/单色，优先带入；彩色转灰度属于处理，不能反改采集模式 |
| 13 | 白平衡模式 white_balance_mode | 影响颜色解释，软件通常提供 | 彩色采集应记录。手动/一次自动/连续自动按设备；取消含糊的“关闭”，只有设备确有未应用校正状态时才提供对应选项 |
| 14 | 白平衡配置 white_balance_settings | 只记录“手动”无法重现通道设置 | 软件可读时保留参数或配置名；不强制所有相机填写三通道，按实际提供的R/B或RGB等控制 |
| 15 | 白平衡色温 white_balance_temperature_K | 有些软件用色温，有些用通道增益 | 与上项统一为设备实际的白平衡设置；若还提供色调则一并保留该设置，不强求两个表达同时填写，不当作光源实测温度 |
| 16 | 白平衡参考 white_balance_reference | 对参考校正有用，但非普通用户每次可提供 | 取消常规独立输入，仅实际做参考校正时关联已有记录或附件 |
| 17 | 照明光源 illumination_source | 光谱影响颜色及对比，身份固定或少量可选 | 设备登记，表征选择/带入；固定光源不能假设等于固定亮度 |
| 18 | 光源设置 illumination_setting | 亮度/电流/档位影响图像，通常易读 | 有读数时本次记录；保留原机单位，不把百分比或旋钮刻度换算为照度。无读数不增加估计百分比 |
| 19 | 滤光配置 filter_configuration | 更换波段对薄层可见度可能影响明显 | 无附件不显示；有附件只选已登记组合，含明确未使用选项。荧光需能表明激发/发射滤光组合 |
| 20 | 光阑 aperture_setting | 可影响照明角度、对比，未必有量化刻度 | 仅可调且可读取时记录孔径光阑；否则由标准配置说明，不能要求估算开口百分比；与视场光阑区分 |
| 21 | X像素尺度 image_scale_um_per_px | 涉及尺寸解释时重要，用户不宜手算 | 与Y统一放图像信息区，优先文件或适用校准配置；没有依据允许缺失，但不能据此自动提供尺寸结论 |
| 22 | Y像素尺度 image_scale_y_um_per_px | 防非等比例采样或重采样歧义 | 同X。只有依据确认两轴相同时才能一值共用，不能无条件将空Y补成X |
| 23 | 采样点数 resolution_px | 文件通常可直接给出宽高，人工重录无益 | 改为图像尺寸，单位px，逐文件自动显示；多张图不强制共用一组尺寸 |
| 24 | 尺度校准来源 scale_calibration | 防错用标尺，有效依据可复用 | 改为像素尺度校准依据，随校准配置引用；去掉OM不适用的“衍射” |
| 25 | 有效位深 image_bit_depth | 灰度定量时有意义，一般用户容易混淆总位数/每通道/有效位数 | 取消常规手填，有可核对元数据时自动附带；当前1–64只是宽范围检查，不应当作设备选项 |
| 26 | 像素合并 binning | 改变采样和信号，可影响尺度适用性 | 固定时并入配置；设备允许切换时选择其实际模式，联动尺度配置；不把裁剪或数字缩放叫像素合并 |
| 27 | 黑电平 camera_offset | 对弱信号和灰度比较有影响，用户未必接触 | 取消普遍手填，固定配置/文件保留；若组内确实经常调整再显示对应控件 |
| 28 | 图像处理 image_processing | 处理可能改变外观及定量意义 | 采集端处理随采集配置/原始文件记录，后处理绑定处理后文件；普通表单不并列两处要求同一说明 |
| 29 | 入射偏振状态 incident_polarization_state | 偏振观察才常用，不应普遍展开 | 仅偏振功能显示；线/圆/椭圆/非偏振按实际光学配置，不能把“未插起偏器”必然当作非偏振 |
| 30 | 检偏方式 analyzer_mode | 偏振观察涉及方向关系 | 改成无检偏器/平行/正交/自定角度等设备适用项；去除常规OM中的“随动”。关系明确相对于起偏方向 |
| 31 | 入射偏振角 incident_polarization_angle_deg | 偏振方向相关观察需要，普通OM无需 | 仅使用相应偏振配置时记录；有参照，按设备角度读数，不要求所有记录填写 |
| 32 | 检偏器角度 analyzer_angle_deg | 自定检偏方向时需要 | 固定夹角配置带入；选择自定时应记录，不能选择固定角度后留成含义不明的空值 |
| 33 | 偏振参照 polarization_reference | 无参照的角度无从解释 | 固定设备零点放配置；若相对样品边缘等变化，记录本次参照。无偏振时不显示 |
| 34 | 样品处理 sample_preparation | 对转移/清洗后样品重要，属于样品状态 | 引用样品处理及当前载体信息；不进仪器预设。已有记录自动关联，仅缺失时补充 |
| 35 | 采集说明 acquisition_note | 仅用于无法由结构字段表达的补充 | 合并为选填备注，取消独立缺项说明负担；提示无需重复“按实际填写”等原则 |

历史字段image_object_type、image_size_metric、illumination_mode保持历史可读，不恢复统计录入，也不重写旧照明原文。此前已停止的覆盖率/对象尺寸/密度录入和材料、层数判断不因本轮重新加入。

**4. 必填规则应区分位置和设备能力**

- 组内设备登记：物镜倍率、标称NA、适用介质作为选用前的核心配置；不要为创建一个空预设就要求全部采集值齐全。相机、光学配置和固定光源要可识别。
- 每次新OM：样品、采集时间、记录方式、所用仪器和物镜、光学配置；单一固定项由明确设备配置带入。数字图像关联采集文件，目视提供观察说明。
- 数字图像重点补齐曝光、增益、颜色模式、白平衡和光源设置中实际适用且设备可提供的值；固定值复用、自动变化值对应采集文件。设备确实不提供的读数不应成为阻断结果留存的必填项。
- 不能将仪器提供的“自动”视为具体曝光/增益值；自动值没有导出时允许缺失，记录可读的模式，不用预设数值冒充。
- 历史、外部测试或旧设备资料不完整时仍可保存已有数据，已有空值不会因新规则失去可读性。外部设备引用的轻量补录应复用现有资料机制，避免要求普通测试者先虚构一台完整的组内设备。
- 这些规则不要求另建一套审核/打分流程，也不要求每个空字段都填一段原因。应通过表单结构和一处必要的保存提示处理。

**5. 公共信息、文件和导出**

| 对象 | 审查结论 |
|---|---|
| 样品及当前载体 | 引用样品。生长衬底与测量时载体可能不同，应从处理/转化关系带入；不能让用户在每张OM重新录入一套衬底数据。二维材料的载体与照明波段可能比大量相机高级参数更直接影响可见度 |
| 采集时间 | 当前默认页面打开时刻，不是图像采集时刻。优先文件元数据或人工录入；元数据无时区不能直接当成UTC。无法读出时不自动把上传时间当采集时间 |
| 测试人与录入者 | 二者分开保留。实际测试人可选择常用人员；系统记录录入者，不把账号自动认作代测操作员 |
| 仪器版本 | 保存快照合理；补录不能总套用最新配置。无需让每位使用者理解版本技术细节，但需能识别实际设备配置 |
| 原始文件 | 保留采集软件导出的原始数据，包括原生容器，不能只收JPEG/PNG。当前数字OM只要求一份标记为raw的文件，没有验证内容是否图像；不应宣称已经验证原始图像内容 |
| 处理后文件 | 与原文件分开、保留来源和处理说明；现有关系校验应保留。仪器直接导出的JPEG也不等于完全未经软件处理，不能只按后缀认定处理状态 |
| 多图 | 同一组实际光学/采集设置可共用一条记录，但曝光、白平衡或尺度变化时需分组或文件级元数据。仅不同视场可共用配置，不强制新增空间测区字段 |
| 图像标尺 | 标尺可供人读，不等同于系统已取得结构化μm/px；优先保留原始图和带标尺的导出图。缩放后标尺与图像必须同步，纯裁剪且未重采样通常不改变μm/px |
| 观察结果 | 保留观察说明，不自动要求描述层数、材料类别或生长成功。不再增加用户此前已暂缓的统计指标 |
| 导出 | 实际typed_conditions、仪器快照、文件来源已有保存/导出路径，应保留。仪器快照中包含可用预设不代表实际选用了所有预设，分析时以本次条件为准 |
| 校准 | 当前整机最近一次校准事件不一定适用于本次相机尺度。只在使用尺度时引用适用配置校准，维护日期不得替代 |

**8. 建议实施顺序**

1. 固定物镜配置与标称NA、相机和实际光学组合先建立，减少普通使用者的文本输入。
2. 收敛常规表单；曝光、增益、白平衡和光源设置按组内设备可读控制填写，取消普遍高级元数据手填。
3. 修正记录方式、仪器切换、预设覆盖、偏振及白平衡语义和前后端适用性。
4. 图像信息与尺度校准统一，保存/导出保留实际值和适用配置；支持多图分组而不强制测区。
5. 用组内实际机型及一份原始导出文件确认可读元数据，再实现针对该格式的导入。不能把尚未实现的自动读取当作本轮已解决的填写方式。

最终文案只保留字段名、单位、必要参照和错误原因。整页不反复出现“实际”“不猜填”“确保可复现”等实现原则；例如“曝光时间（ms）”“相机增益（dB）”“白平衡”“光源亮度（%）”，单位以设备为准。备注可以没有占位说明。
