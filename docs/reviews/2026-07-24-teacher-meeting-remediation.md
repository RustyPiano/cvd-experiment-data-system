## 7. 需要导师/组内裁定的 11 个专业问题

这些问题不应由工程人员猜答案，也不应以自由文本空壳掩盖。当前实现优先保存原始事实，并为“其他”要求明确名称或参数。

| 编号 | 请裁定的问题 | 当前安全处理 |
| ---- | ------------ | ------------ |
| P-01 | “观察到的现象”词表应细到什么粒度，哪些属于组内稳定选项 | 现有客观词表继续使用；未覆盖现象选择“其他”并强制填写具体描述 |
| P-02 | SEM 中“覆盖率”的组内标准叫法与量化方式 | 不自行把主观等级冒充定量值；待确认名称、单位/区间和测量方法后进入字段源 |
| P-03 | 堆垛类型需要区分到什么粒度 | 先保存可确认的结构角色、层序和具名事实，不扩造未经确认的枚举 |
| P-04 | 前驱体“外观”应采用哪些稳定选项 | 现有词表外内容具名保存；待实际实验人汇总高频值后再冻结 |
| P-05 | 实验前气体操作统一称为“气路置换”“洗气”还是“吹扫” | 当前结构已保存循环次数、气体、批次与流量；名称待组内统一 |
| P-06 | 低压 CVD 是否每条制备记录都要记录漏率，以及它属于装置校验还是实验过程 | 当前不虚构必填位置；确认归属、单位和测量时点后再加入单一源 |
| P-07 | 多气体比例采用什么组内标准名称 | 系统先按同时间段各气体流量派生，不重复存一份可能不一致的比例 |
| P-08 | 掺杂体系组成角色最终采用“本征材料”“基体”还是“主体”，复杂官能团化学式用什么组内示例 | 权威事实保存在组成明细；术语和示例待裁定后统一替换 |
| P-09 | 压片等前驱体处理方式的最小参数模板是什么 | 未确认参数使用具名“参数—值—单位”，不接受无单位、无名称的自由文本 |
| P-10 | 低压系统是否需要记录真空泵类型、功率和转速，哪些属于装置版本、哪些属于每炉条件 | 当前只把确定的绝对工作压力放入炉次；设备能力不从字段表猜写，待确认归属后进入 Setup 或过程结构 |
| P-11 | 物料是否必须做真实瓶装试录；目录号是否必填；CoA 与瓶身/包装标签照片的证据边界如何划分 | 供应商、目录号保持可选；CoA 与标签附件分角色保存；气瓶编号、纯度和等级已具名记录，待组内确定最小证据集 |
