## 最新收敛方案（覆盖下文早期命名建议）

用户明确指出：这里登记的是附加能力，并不限于场。“外场与等离子体配置”的建议撤回，最新建议名称为“装置附加能力”；光照、电场、等离子体是具体选项，“其他”继续支持具名多项。实际使用入口相应可称“本次使用的附加功能”。用户随后授权按讨论内容实施。

目标材料不再沿用本征/掺杂/合金/异质/同质的互斥顶层分类。已采用的流程为：

1. **结构形式**：单一区域、垂直堆叠、横向拼接。单一区域表示只需要一份目标材料定义，不是单个晶畴，也不是表征测区；多片相同组成和结构的目标晶片无需逐片定义区域。
2. **每个材料区域**：填写化学式；合金可改为按组分及比例填写；独立填写目标晶体结构、目标层数（层状材料适用），以及选填的掺杂元素、含量、位点。合金和掺杂可以同时存在，各区域可不同。
3. 单一区域只显示一张材料卡；垂直堆叠至少两张，按从下到上排序并分别填写材料层数；横向拼接至少两张区域卡，各区域层数独立。层序与材料层数是不同概念。
4. MoTe₂ 区域 A=2H、区域 B=1T′，选择横向拼接，即明确表达同质异相目标；MoS₂ 与 WS₂ 分别填写则表达异质目标。无需另建“同质结构”专用数据对象。摘要显示用户填写的组成、结构及排列，不擅自推断已制得结构或未填写的结类型。

“目标晶体结构”保留。此前以“没有录完整原子结构”为由建议强制改名，要求过严：用晶相/多型选择器表达目标晶体结构在这里合理。用具体例子说明：MoS₂ 表达元素组成与比例；2H、3R 表达不同结构形式，体相中二者的层间堆垛不同；空间群是描述晶体对称性的进一步信息。页面重点展示结构名称和“不指定”，体相参照解释、空间群放详细信息，不把“体相参照”硬塞进主标签。层状材料的体相候选仍仅是参照，不自动声明单层实物具有相应体相堆垛。

实现边界：已复用现有区域与组成关系，并同步修正合金单区域限制与横向层数一致限制；保留历史读取。

## 同质异构结

如果指同一化学组成、不同晶相之间的界面，建议称“同质异相结构/结”。CVD 已有原位生长 2H/1T′-MoTe₂ 横向同质结的实验证据。[ACS Nano 原始论文](https://pubs.acs.org/doi/10.1021/acsnano.9b02785)

UI 当前只有本征、掺杂、合金、异质结构；但底层 `material_regions` 已能记录同一化学式、不同晶相的多个区域，后端不要求区域化学式各不相同。因此是缺少准确入口，不是完全没有存储位置。

建议增加“同质结构”；其中明确所指差异。如果本轮只处理晶相不同，入口直接命名“同质异相结构”即可。空间排列仍独立选择“横向拼接 / 垂直堆叠”，每个区域记录化学式和晶相，例如 A = MoTe₂ / 2H，B = MoTe₂ / 1T′。复用现有区域模型，不额外建立一套目标对象。不能只比较空间群号判定晶相是否相同；两相共存也不自动等于已形成结，目标与实际结果继续分开。

## 目标产物形态与颗粒

现有词表混合了连续性（连续膜、分立）、几何形态（片、带、线、管、棒、颗粒、块）和晶体学对象（晶体、晶畴）。连续膜可以含有多个晶畴，晶畴不等于分立小片。CVD 实验也明确区分分立单晶与含晶界的连续膜。[Nature Communications 原始论文](https://www.nature.com/articles/s41467-019-09269-9)

建议采用两个轻量选填项：

| 字段 | 内容 |
| --- | --- |
| 目标几何形态 | 片/膜状、带状、线状、管状、棒状、颗粒状、块状、其他（具名） |
| 目标成膜形式 | 仅片/膜状展开：分立片状、连续膜；无预设时留空 |

分立片状再展开平面轮廓；连续膜不要求预设内部晶畴轮廓。均为实验前的计划，不重新引入实测覆盖率或要求预判实际生长结果。“希望单晶”属于结晶性，当前可写实验目标，不混入形态分类。

“颗粒状”建议指相对紧凑的三维颗粒外形，不指显微图像中的一个点。小片、成核点、污染或投影都可能呈点状；量子点另涉及量子限域，不能与一般颗粒互换。[IUPAC 量子限域定义](https://goldbook.iupac.org/terms/view/08861/plain)

颗粒/块状、带/线/棒之间目前也没有组内确认的尺寸或长径比阈值。应解释产品形式，不凭空设定数值分界；真要按大小筛选，应另用尺寸。

## 其他规则多边形

确有三角、四边、六边以外的外轮廓：高指数铜表面 CVD 生长五边形石墨烯晶畴已有原始报道。这不能推成“严格正五边形”，也不意味着晶格具有五重周期旋转对称。[Nano Research 原始论文](https://www.sciopen.com/article/10.1007/s12274-016-1107-9)

建议改为“其他多边形”，选中后就地填写名称（例如五边形）；不必铺开大量低频选项。三角形/六边形按近似轮廓记录，不要求严格等边等角。截角三角形与六边形有交集，可将仍明显保留三长边三短边特征的归为前者，这是录入约定。相邻“枝晶状/分形”建议简化为“枝晶状”，有分枝不足以宣称分形性质。

## 设备其他外场

根因：`field_devices` 和 `field_device_other_name` 是两个独立字段，被通用两列表单顺序排到不相邻的位置；单一源同时明确限制一个其他名称。单改 CSS 无法解决多项保存。

建议外场组独占一行；常用能力继续多选，“其他”在组内下一行，其输入紧随其后。一行一个名称，提供添加和移除；直接沿用项目中表征仪器“其他方法逐项填写”的交互。

- “无”与所有能力互斥；名称去首尾空格、非空、去重，错误跟随对应条目。
- 临时取消可保留本地草稿以便恢复；提交只保存仍选择的能力，删除已记录内容应有明确动作。
- 保存名称列表，不用逗号拼接。旧单名称兼容为单项列表，旧装置版本和锁定快照保留原文，不按标点猜拆。
- 实验过程必须能分别选择各个自定义能力，各自填写时间和参数。目前该处只拿单一名称替换“其他”的显示名，需要一起调整。
- 装置能力与本炉实际启用继续分开；有具名其他入口后，不必仅因示例就把磁场升为固定分类。

本轮交互示意支持增删、重复名提示、“无”互斥及草稿恢复，不连接业务保存。

## 溶剂擦拭

当前已支持“衬底处理 → 溶剂清洗 → 选择溶剂 → 清洗方式=擦拭”。擦拭时间选填，超声/浸泡时间必填。溶剂清洁配合机械擦洗确实存在。[UTEP 衬底清洁说明](https://www.utep.edu/engineering/nanomil/processes/cleaning.html)

不再增加同级“溶剂擦拭”，以免重复。可在擦拭分支补选填“擦拭材料”（无尘布、拭子等）。该字段用于记录真实做法，不暗示擦拭适合所有衬底或已生长薄膜；也不强制虚假的精确时长。

## 紫外/臭氧参数

当前 `uv_ozone_treatment` 前后端只有必填时长。制造商明确指出臭氧浓度、样品到光源的距离会影响清洁速率，并提供可调样品台与介质入口。[Jelight 设备说明](https://www.jelight.com/uvo-cleaner/)

首先把方法名写清：如果是 UV–O₃ 联合设备，叫“紫外臭氧联合处理”；如果确实存在仅紫外、仅臭氧，就分别明确模式，不用斜杠合并三个过程。

| 参数 | 建议要求 |
| --- | --- |
| 处理模式与时长 | 模式明确，时间必填；只使用联合设备时方法名可直接表达模式 |
| 设备标识或固定程序 | 推荐，用于追溯固定配置，避免每炉重复填规格 |
| 样品到光源距离 | 有 UV 且距离可调时推荐，单位 mm |
| 气氛 | 空气、通入氧气、其他；主动供气时记录实际已知流量 |
| 加热条件 | 使用控温台时填设定温度，不把室温默认成样品实测温度 |
| 波长、样品处辐照度、臭氧浓度 | 设备资料或实测可得时记录单位与依据；未知可留空 |

灯具电功率不能替代样品处辐照度。不能只加“功率”就认为条件完整。波长/灯型号可随设备或程序引用，本轮不提前建设独立清洗仪器管理系统。

## 实际溶液用量

当前滴涂显示“滴加体积”，其他需用量处理显示“用量”。溶液分支应按用户要求统一为“实际溶液用量”，并明确滴涂/旋涂所指为实际加入的体积，推荐 μL/mL；固体直接投料仍记称量值。

文字替换还需解决计量对象：

1. 滴涂/旋涂体积不等于干燥后负载量，没有留存比例证据时不能自动推算后者。
2. 当前每个 `ingredients[]` 物料各有 `amount`。若含 A/B 两种溶质的一份混合溶液共滴加 20 μL，应在该份溶液操作记录一次 20 μL，再分别记录 A/B 浓度。不能当成两次 20 μL 相加。若实际分别滴加两份溶液，才分别记录体积。实施时应结合现有 SourceLoad 与有序处理步骤明确归属，不能把所有固体物料 amount 都改名为溶液用量。
3. 浸渍液槽体积不等于消耗量或吸附量。仅浸渍当前不强制用量合理；需要时可选填“浸渍液体积”，不将其误作负载量。
4. 旋涂目前没有像滴涂一样限定体积单位，若统一溶液体积语义，该校验要同步修正。

## 命名复核补充（2026-09-09）

用户进一步询问名称是否专业、是否存在歧义。以下为建议，不自动覆盖既定词表。判断标准是读者能否明确对象、维度、计量口径与证据状态，而非用词越长越好。

### 含义基本不变，可以优先调整

| 现名 | 建议名称 | 理由 |
| --- | --- | --- |
| 环境湿度 | 环境相对湿度 | 字段实际以 %RH 记录 |
| 壁型 | 反应器类型（热壁/冷壁） | 避免与炉管壁厚、材质或截面混淆；选项可写热壁式、冷壁式 |
| 目标含量（掺杂分支） | 目标掺杂含量 | 明确指掺杂物；百分比的分母定义仍需另行明确 |
| 目标位点（掺杂分支） | 目标掺杂位点 | 避免与衬底位置、目标区域混淆 |
| 颗粒 | 颗粒状 | 与带状、线状保持形态词的一致性；不等于点状或量子点 |
| 外场能力 | 装置附加能力 | 用户明确功能不限于场；撤回此前“外场与等离子体配置”的建议 |

“等离子体”是含电子、离子等粒子的至少部分电离气体，而非场本身。[IUPAC 定义](https://goldbook.iupac.org/terms/view/P04687) 热壁与冷壁是 CVD 反应器的通行分类，明确字段对象即可，无需发明“热型”等新术语。[Open University 说明](https://www.open.edu/openlearn/course/view.php?id=14060)

### 涉及概念或分类范围，不能只替换字符串

- **本征材料**：当前入口实际表达未主动掺杂。未有意掺杂不保证电子学本征性质；二维材料已有非故意掺杂实例。[原始研究](https://www.nature.com/articles/s41699-023-00406-z) 建议在组成/掺杂维度使用“未有意掺杂”，避免把它与异质结构并列为互斥体系；简单改回“单一材料”也不能解决维度问题。
- **目标晶体结构 / 基体晶体结构**：最新建议保留原名，撤回此前将主标签改成“目标晶相（体相参照）”的建议。选择晶相/多型来表达目标晶体结构在本表单中合理；空间群和体相参照解释放详细信息。晶体结构与对称性的区别用示例说明即可。[IUCr 说明](https://journals.iucr.org/j/issues/2018/05/00/in5013/)
- **分立片状晶体/晶畴**：形态项改为“片/膜状”，成膜形式另选“分立片状 / 连续膜”。晶畴与外形分开，不把“晶畴”简单改成“晶粒”后保留混维。
- **块状晶体**：若该字段只表达几何形态，用“块状”；是否晶态、是否单晶属于另一个维度。
- **其他规则多边形**：建议“其他多边形”。这是放宽字面范围，不是同义替换；旧记录不据此补推边数或等边等角性质。
- **枝晶状/分形**：建议新录入用“枝晶状”，已有明确分形信息不应被清除；有分枝不自动意味着分形。
- **紫外/臭氧处理**：UV/ozone 是通行写法，不应称其不专业。中文使用“紫外臭氧联合处理（UV–O₃）”是为了明确联合过程；仅紫外、仅臭氧确有实际需求时独立表达。[Jelight 用语与设备说明](https://www.jelight.com/uvo-cleaner/)
- **用量 / 滴加体积**：滴加体积本身准确。统一成“实际溶液用量”时必须限定在溶液分支，并说明实际加入体积；固体称量、浸渍液槽体积、干燥后负载量不能一起改成此名。
- **溶液浓度**：单溶质上下文通常清楚；混合溶液应显示“该组分在溶液中的浓度”，并明确浓度单位/基准，不让用户误填总溶质浓度。

不建议为显得专业而改动“目标平面轮廓”“溶剂清洗”“超声、浸泡、冲洗、擦拭”“旋涂、滴涂、浸渍”“氮气吹干”“衬底”“目标层数”等已有明确上下文的名称。目标平面轮廓需要修正的是选项范围；仅浸泡处理不应仅凭内部键 dip_coat 就强改为强调提拉成膜的“浸涂”。
