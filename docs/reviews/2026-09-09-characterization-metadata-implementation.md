**必填与缺项策略**

- 原有最低保存要求保留；数字 OM 新增仪器和原始文件门槛；“其他成像/扫描/几何”选中后要求具名说明。模式不相容、非法单位数值、跨方法/跨样品文件、重复或不闭合来源直接拒绝。
- 功率、时间、脉宽/重复频率、XRD 固定角等可因设备不提供而缺失的参数使用明确“尚未记录”提示，允许保存真实缺项。页面及详情不以此推定室温、零值、未处理或完整可复现。
- 同一条记录共用一套采集条件。不同设置拆成不同测量；映射/参数扫描用原始文件保存逐点条件，并可填写相应列/通道位置。本批不把单一数值伪装成整个扫描的条件。
- 切换功率单位继续确认并清空原数值；切换影响结果的模式继续确认后清空结果。移除原始文件前需解除其处理后文件依赖；已保存且被来源关系引用的文件受删除保护。
- 图像统计、AFM 粗糙度、元素定量、统计与不确定度编辑器、峰归属、材料判定、强制测区管理继续暂缓。

**本次发现并修复的导出问题**

SQLite 导出设置连接级 `PRAGMA query_only = ON`，旧清理顺序先回滚并归还连接，随后可能在另一个连接关闭只读。真实浏览器复现为一次导出后，后续上传偶发“attempt to write a readonly database”。现改为归还连接前恢复该连接状态，并由 Session.close 回滚/释放。共用 JSON/ZIP 导出均使用此清理路径，PostgreSQL 的只读事务设置保持原逻辑。

新增双连接池回归测试在修复前稳定得到 `[1, 0]`，修复后为 `[0, 0]`；另有 OM/AFM 保存—详情—导出及引用文件保护回归。
