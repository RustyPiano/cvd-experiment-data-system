# OM配置与采集表单实施 · alpha.45

用户在[OM专项审查](./2026-09-10-om-field-review.md)后授权修改。本轮为本地实现，未部署；既有前端整改继续保留。

已完成：

- 仪器OM能力内分别维护物镜、相机、光学配置、尺度校准目录。物镜倍率、标称NA、介质为登记必填；干式NA条件上限、偏振选项与角度依赖由字段源驱动。目录名称唯一，选择记录指向指定仪器版本。
- 相机声明固定参数、每次可调参数、支持的曝光/白平衡模式及原生格式扩展名。表征按选择带入固定配置，只提供实际声明的可调项；未声明目录的旧仪器仍可人工补录。
- 尺度校准绑定物镜、相机、光学配置及像素合并；配置名称记录转接/变倍/采样条件。选用尺度时锁定适用采样参数，切换硬件清除原尺度；服务端拒绝错误引用及固定值篡改。
- 常用预设限定到采集设置，不能保存样品处理、缺项说明和观察结果。OM应用预设保留观察说明、文件及备注；自动曝光/白平衡预设不把预设数值当成自动调整后的数值。切换仪器、版本、物镜或相机清理旧设备参数，保留本次观察及文件。
- 记录方式必选，数字图像分支要求仪器与原始采集文件；采集时间初始为空，不采用打开页面的时间。已有样品当前载体直接显示。
- 常规OM不再手填图像宽高、有效位深、黑电平、白平衡参考和独立样品处理文本。偏振参数通过实际光学配置登记/按需调整；常规文案去掉重复“实际”和不适用的“衍射”等词。配置参数默认折叠，物镜选项显示NA。
- Pillow识别、验证并解码常见图像的首帧，取得宽、高、格式、模式和帧数，逐文件存入metadata_json.image并进入详情/导出。不推断有效位深、曝光、白平衡、像素尺度或无时区的采集时间。原生容器按相机声明允许存档，不标记为已解码；非图像且非已声明原生格式不能充当数字OM原始数据。已上传旧文件在首次需要时读取图像信息。
- 保存记录包含本次instrument_configuration和条件规则版本；实际typed_conditions及仪器快照保留。历史记录不会因为新增记录方式必填而被重新判为缺失，旧值不改写。

字段源版本为v4.0-alpha.45，OM条件36项（新增物镜倍率）；实验字段126、实体字段67、R0 26不变。生成模型、JSON契约、OpenAPI、前端字段元数据及AJV校验器和xlsx同步。没有新增数据库结构或迁移。新增运行依赖Pillow 12.3.0（约束<13），其余Python包版本不变；uv更新锁文件格式及制品上传时间。
