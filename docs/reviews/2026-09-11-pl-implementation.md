# PL 整改实施记录 · 2026-09-11

按用户“进行修改”的授权实施[PL 逐项审查](./2026-09-11-pl-field-review.md)。本地契约为 **v4.0-alpha.47 / INTERNAL_VALIDATION**；生产基线仍按 STATUS 记录为 alpha.43。本轮未提交、推送或部署，无新增依赖或数据库迁移。

## 设备登记与采集

- 复用 OM/Raman 的目录编辑器、选择组件、版本快照与验证，增加 `capabilities[].configuration.pl`。目录包括激发光源、物镜或探头、光谱配置；光谱配置引用对应光源。
- 激发光源登记类型、波长、连续/脉冲方式和功率控制单位。固定值随选择带入，明确标为可调的波长、脉宽和重复频率可在本次采集修改。
- 显微物镜的倍率、NA、介质登记必填，干式 NA <1；探头不要求填写显微物镜参数。表征时不再出现独立于所选物镜的可编辑 NA。
- 光谱配置登记光栅、探测器、滤光配置和收集光路，以及适用的增益、狭缝、共焦、偏振、累积方式与校准依据。固定项隐藏于本次输入，配置参数可展开查看。
- 区分物理狭缝宽度（μm）与发射光谱带宽（nm）；选择带宽设置后清理并排除物理狭缝输入。保留旧的仅含物理狭缝宽度配置。逐波长扫描配置要求波长步长；阵列采集不要求扫描步长。积分时间仍按设备的曝光/每点积分定义记录。
- 配置完整的组内仪器要求采集形式、功率设置及单位、积分时间、累积次数、发射范围完整。序列中声明变化的参数免填单值。无目录的历史或外部仪器保留人工补录路径，不强制补造旧数据。
- 软件功率设置与样品处测得功率独立保存，可同时记录；百分比、仪器 mW 和档位分别处理，不自动换算百分比。功率设置修改单位时清理旧值，单位不匹配的功率预设不能套到所选配置。
- 温度条件区分“室温、未控温”和“记录温度”，后者要求数值及来源；环境采用空气、真空、气体、液体、其他，按选择补充名称。样品的当前载体在 PL 同样显示。

## 预设、序列与偏振

- PL 常用预设仅保存可复用采集设置。样品处测值、样品处理、备注、环境实测值和文件响应校正状态不得作为预设。
- 应用预设只覆盖匹配采集项，保护固定配置，保留峰、观察和来源。切换仪器、版本或硬件配置会清理原设备参数，保留样品独立信息、结果和文件。
- 空间扫描和参数序列引用本次原始扫描文件 `scan_file_id`，填写轴、单位和列名。`variable_conditions` 支持功率、样品处功率、积分时间、温度、角度、脉宽、重复频率及经过时间；时间序列可选“时间”，无需虚构一个变化的功率。
- 变化参数不再保存一个代表整个序列的标量，固定设备参数不能声明为变化参数。多谱文件的峰结果需要谱号、坐标或聚合范围。
- 线偏振检测的平行/正交要求线偏振入射，自定角度需填写角度和参照。圆偏振检测使用独立模式，分别记录入射与检测的 σ+/σ− 通道以及传播/观察方向约定，不将其与线偏振平行/正交混用。
- 脉冲激发要求脉宽和重复频率，固定值在设备中登记；后端检查脉宽小于重复周期。本轮仍为发射光谱及其扫描/序列，不新增 TRPL 衰减和 PLE 的专用结果模型。

## 单位与峰结果

- 发射范围保存 nm，界面可切换 nm/eV。能量坐标的上下限会对应到相反的波长端点，切换单位不改变保存条件；端点必须大于零。
- 温度支持 K/℃，脉宽支持 fs/ps/ns，频率支持 MHz/kHz/Hz；分别保存 K、fs、MHz。负摄氏温度不会被原生输入控件误拒绝。
- PL 峰位继续支持 nm/eV。峰位按对应坐标检查是否在记录范围内；能量轴的半高全宽可使用 meV 输入并保存为 eV，40 meV 保存为 0.040 eV。
- 单位转换不自动改写谱密度、峰面积或拟合线形；改变峰位轴时沿用确认后清空峰参数的行为。
- PL 峰强度单位不再默认 a.u.，只填写峰高/面积时显示；FWHM、峰高或面积要求提取与基线依据。这里沿用简短依据字段，没有新增完整分析流程。
- 峰可引用本次原始谱或处理后谱，说明性附件不可作峰来源；“对应原始光谱”文案改为“来源光谱”。已知文件强度单位须与引用它的强度结果一致，合法换算通过处理后文件及处理说明表达。

## 文件校正与适用校准

- 新增 `file_response_corrections`，按本次 raw/processed 文件 ID 保存 `{status, source?}`。状态为 applied/not_applied，未填写则不创建条目；已应用时要求校正曲线或报告来源。
- 同次测量中的原始谱、校正谱和归一化谱各自记录。旧的测量级响应校正字段保留历史读取，不进入新表单和预设。
- 校正来源可引用设备中已有曲线或仪器报告；当前为文本依据，不宣称已自动解析、验证或应用曲线。
- PL 校准事件必须明确 `method_profile: PL`、仪器版本和所选组件。波长、发射响应、功率分别处理；最近一次 Raman 校准不能被当成本次 PL 校准。
- 功率校准进一步匹配已记录的激发波长和脉冲条件；发射响应校准需有覆盖本次发射范围的波段。未满足范围或条件的事件不会被选为适用记录。
- 保存测量时冻结配置与校准信息。仪器新增版本或后来补登记校准，不改写已保存记录。
- 文件校正、单位、扫描来源、变化参数和所选配置进入详情及科学 JSON/CSV 导出。CSV 沿用科学记录递归展开路径。

## 字段与兼容范围

- 字段源、Pydantic 生成物、JSON Schema、字段字典、OpenAPI、前端元数据、AJV 校验器和 xlsx 已更新。
- 总表仍为 126 个实验字段、67 个实体字段、26 个 R0 标记。PL profile 包含 54 个条件定义，其中 5 个仅保留历史读取；49 个非历史项包含管理员配置和条件展开项，不是要求每次手填 49 项。
- Schema 增加非适用方法的配置、扫描和文件元数据限制，并同步响应校正来源要求。文件跨引用、实际配置匹配、峰与范围/文件单位等仍由后端保存校验完成，不能以通用 JSON Schema 通过代替全部业务校验。
- 范围顺序沿用项目的 `x-cvd-ordered` 扩展；普通 JSON Schema 消费者需支持该扩展或自行校验。PL 脉宽/重复周期关系也由后端补验。
- 没有修改历史数据库记录、恢复激子/材料/层数判定，或增加强制测区、PLQY、寿命结果。
- 同一工作区另有衬底“紫外/臭氧表面处理”文案调整，本轮保留其源码、字段源与日志；不将该变化归入 PL 设计。
