# AFM 字段复核（2026-09-11）

## 结论

AFM 当前字段比 SHG/Raman 更接近可用：扫描尺寸必填、模式/探针/采样点数/扫描线频率为核心条件，粗糙度和台阶高度留在结果域也正确。主要问题是“探针”仍为自由文本、模式与反馈字段没有充分联动、扫描尺寸只允许单一单位、处理字段混入条件区，以及把大量低频控制参数全部展示为选填。

## 依据

AFM 的高度和形貌结果直接受探针几何、扫描尺寸、采样点数、扫描速率、反馈设定和数据平整化影响。NIST 的 AFM 校准指南将 X/Y/Z 轴尺度、扫描速率、探针、反馈和图像处理列为可追溯测量条件。ISO 25178-700 对表面纹理仪器的校准和测量条件要求尺度校准、测量区域和滤波/处理可追溯。相关 AFM 实验报告通常同时给出模式、探针型号、共振频率、扫描尺寸、分辨率和扫描速率。

## 当前设计判断

| 字段 | 判断 | 修改建议 |
|---|---|---|
| `scan_size_um` | 必填合理，直接决定空间尺度 | 保留；允许 X/Y 非方形。 |
| `mode` | 核心字段，但接触/轻敲/非接触/峰值力混在同一层 | 保留；“其他”需说明；按模式显示反馈字段。 |
| `probe` | 影响分辨率和力学响应，但自由文本不可复用 | 移入 AFM 设备配置目录；表征时选择探针。 |
| `resolution_px` | 影响采样间隔，适合保留 | 与扫描尺寸一起显示有效像素尺寸。 |
| `scan_rate_hz` | 重要，但“线/秒或往返/秒”口径必须结构化 | 保留数值，`scan_rate_definition` 改为选项。 |
| `feedback_setpoint` | 对接触力或振幅反馈有影响 | 仅在接触/轻敲/非接触/峰值力相关模式显示；保留单位。 |
| `free_amplitude` | 仅振动模式适用 | 当前条件正确，应与 setpoint 同组。 |
| `feedback_gains` | 可影响跟踪，但用户常从报告取得 | 选填自由文本可保留，放入“高级参数”。 |
| `drive_frequency_kHz` | 只在振动模式有意义 | 按模式显示；最好从探针目录预填，允许本次实测覆盖。 |
| `height_processing` | 属于结果/处理，不是采集条件 | 移到处理后文件信息；保留处理前后文件关系。 |
| `height_calibration` / `scale_calibration` | 对厚度和尺寸可信度关键 | 保留；绑定文件或校准记录，不要只存一句文本。 |
| `measurement_environment` | 液体、空气、真空会改变探针与反馈 | 保留；用有限选项，其他补充说明。 |
| `scan_direction` / `scan_rotation_deg` | 对各向异性和滞后判断有用 | 保留；非关键模式可折叠。 |

## 最小修改方案

1. 新增 AFM 设备配置目录：探针型号、悬臂共振频率/标称弹簧常数、探针类型作为固定配置；本次记录只选择配置。
2. `scan_rate_definition` 改为“线/秒、往返/秒、仪器原定义”三个选项，删除自由文本歧义。
3. 按模式条件显示 setpoint、free amplitude、drive frequency；模式切换时清除不适用值。
4. 将 `height_processing` 移到文件处理信息，保留原始高度文件与处理后文件的来源关系。
5. 不新增粗糙度统计、滤波参数或材料判定字段；粗糙度/台阶高度继续作为结果，避免把派生结果误当采集条件。

本报告只完成复核，尚未修改 AFM 字段源或业务代码。
