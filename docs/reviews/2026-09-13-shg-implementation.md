# SHG 整改实施记录 · 2026-09-13

按用户“进行修改”的授权实施 [SHG 逐项复核](./2026-09-11-shg-field-review.md)。本地契约为 **v4.0-alpha.48 / INTERNAL_VALIDATION**，生产基线仍为 STATUS 记录的 alpha.43。未提交、推送或部署，无新增依赖，无数据库迁移。

## 1. 分类

- `data_type`（光谱/偏振扫描/图像/功率扫描）改为仅供历史读取。新记录由三项共同表达：
  - **检测方式** `detection_kind`：光谱仪、单通道探测器（PMT/APD）、相机，属于新增必填项；
  - **采集形式** `acquisition_kind`：单点/单幅、空间扫描、参数序列；
  - **变化参数**：复用 PL 的 `variable_conditions` 与 `scan_file_id`。
- 可选变化参数：功率设置、测得功率、激发波长（可调谐光源）、入射偏振角、半波片机械角、样品转角、检偏器角度、时间。偏振分辨成像记为“空间扫描 + 角度”，相机图像栈记为“参数序列 + 角度”，功率依赖光谱记为“光谱仪 + 参数序列 + 功率设置”。
- 时间字段由检测方式决定：光谱仪与单通道单点/序列用积分时间，单通道空间扫描用像素驻留时间，相机用曝光时间。图像尺寸与 X/Y 像素尺寸仅在相机检测或空间扫描时适用。前端显示、草稿清理、预设和后端保存使用同一规则。
- 峰结果仅在光谱仪检测下可用。光谱范围（nm）进入常用区，并核对峰位是否在范围内（nm/eV）。不强制峰位接近 λ/2。

## 2. 设备登记与采集

- 新增 `capabilities[].configuration.shg`，复用光学目录编辑器、选择组件、版本快照和配置一致性校验。
  - **激发光源**：波长、激发方式、功率设置单位必填；脉冲光源的标称脉宽和重复频率必填。波长、脉宽、频率可声明为可调。
  - **物镜**：倍率、NA、浸没介质必填，干式 NA 必须 <1。
  - **检测配置**：检测方式、探测器、滤光配置、收集光路必填。光栅与狭缝仅用于光谱仪。可登记固定偏振状态、检偏方式和角度参照。检测配置须引用适用的激发光源。
- 配置完整的组内仪器，采集形式、功率设置及单位、累积或平均次数，以及与检测方式对应的时间字段为必填。变化参数免填单值；固定设备参数不能声明为变化参数。
- 功率改为“功率设置”加选填的“测得功率（mW）”，二者可同时记录。填写测得功率时，必须选择测量位置：样品处或物镜前。
- 收集光路为“反射（背向收集）/透射（前向收集）/其他”。累积方式只保留求和和平均。
- 检偏方式为“未使用/平行/正交/自定角度”；平行、正交仅适用于线偏振入射。入射偏振角、半波片机械角、样品转角要求填写角度参照和检偏方式；自定角度要求填写检偏器角度。两个角度参照字段合并为“角度参照”（零点及正方向）。
- 入射偏振角与半波片机械角只能记录其一，前后端均会校验。选择半波片机械角作为变化参数后，入射偏振角的输入框和复选框隐藏。半波片机械角只作为变化参数，不提供单值输入。
- 当前载体在 SHG 表征页显示。原始或处理后文件可记录强度单位（counts、counts/s、a.u.）。

## 3. 预设、切换与校准

- SHG 预设只允许功率设置及单位、积分/驻留/曝光时间、累积次数、光谱范围、狭缝、增益。检测方式、样品处理、备注、测得功率等本次记录的内容会被前后端拒绝。
- 预设中的时间字段须与检测方式一致：驻留时间不能与积分时间并存，相机曝光不能与光谱范围并存。编辑器只提供仪器已登记检测方式对应的时间和光谱字段；填写其中一种时间后，其余时间字段隐藏。
- 应用预设只覆盖匹配的采集项，保留峰、观察说明、文件来源及固定配置。切换仪器、版本或配置时清理原设备参数，保留采集形式、扫描参数、表征前处理和备注。
- 设备目录的“每次可调整的参数”不再列出所登记硬件不适用的项，例如 PMT 检测配置不再显示狭缝宽度。该规则同样作用于 OM/Raman/PL。
- 仪器能力的 `configuration` 仅接受 `om/raman/pl/shg/presets/method_names`，未知键返回 422。
- 适用校准按 `method_profile: SHG`、仪器版本和所选组件匹配。偏振校准引用激发光源与检测配置；功率校准引用激发光源与物镜，并匹配激发波长及脉冲条件。Raman 或 PL 的校准事件不会被选用。
- 后端对 SHG 同样检查脉宽小于重复周期（此前只检查 PL）。

## 4. 与复核报告的差异

| 报告建议 | 实施 | 理由 |
|---|---|---|
| 保留角度范围、角度步长 | 改为仅供历史读取，逐角度数值保存在关联的扫描文件，并填写轴与列名 | 同一信息在文件中已有，另填一份会重复，且可能与文件不一致。需要恢复时可以作为选填项加回 |
| “旋转部件”选择中包含共路半波片 | 记为“半波片机械角”变化参数加检偏方式“平行/正交” | 共路半波片的效果就是检测方向随入射方向同步旋转，现有两项已能表达，不再增加字段 |
| 样品处功率 | 改为“测得功率 + 测量位置” | 本组的测量位置尚未确认。文献中两种测量位置都有，同一数值在物镜前后含义不同 |

## 5. 字段与兼容范围

- 字段源、Pydantic 生成物、JSON Schema、字段字典、OpenAPI 类型、前端元数据、AJV 校验器和 xlsx 已同步。总表仍为 126 个实验字段、67 个实体字段、26 个 R0。SHG profile 共 55 个条件定义，其中 14 个仅供历史读取。
- **API 兼容性收紧**：新建 SHG 记录必须提供 `detection_kind`，只含 `data_type` 的旧式载荷会被拒绝。已保存的历史记录不重新校验，详情与导出照常显示旧字段。
- JSON Schema 中，被声明为变化参数的必填字段（例如激发波长）不再无条件要求出现在 `typed_conditions` 中。检测方式与时间或图像字段的对应、角度互斥和脉宽周期由后端补验，通用 Schema 通过不等于保存校验通过。
- 没有新增 χ⁽²⁾、取向角、功率斜率、层数或对称性结果，也没有新增温度或环境字段。

## 7. 待确认与未实现

- 本组 SHG 的检测方式（PMT 扫描、光谱仪、相机）和功率测量位置，仓库中没有记录；当前实现三种检测方式和两种测量位置均支持，登记时按实际设备填写。
- 原生文件（PMT 图像栈、光谱文件）不做自动解析，需要真实机型和样本文件。
