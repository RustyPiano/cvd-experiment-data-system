# SHG 字段复核（2026-09-11）

本次复核针对当前 `field-source.yaml` 的 SHG 条件（必填 2 项、选填 43 项）及现有表单逻辑。判断标准是：字段是否直接影响二次谐波信号、是否能由实验人员从仪器界面或原始文件取得、是否与数据类型一致。

## 结论

当前 SHG 设计把四种数据类型、普通采集、偏振扫描、功率扫描和成像字段全部放在同一组“选填字段”中，录入负担大，且关键字段没有按条件收敛。`excitation_wavelength_nm` 必填是合理的；`data_type` 必填合理，但应据此展开不同字段。`objective` 与 `objective_na` 重复，固定设备配置应移入仪器目录；`excitation_power_value` 与 `excitation_power_basis` 目前把数值和口径拆开但没有单位/范围闭环；脉冲参数只在脉冲模式出现，方向正确。

## 依据

SHG 信号对脉冲宽度、平均功率、波长、偏振、物镜 NA、相互作用长度、收集几何和探测系统均敏感。[SHG microscopy 优化研究](https://www.sciencedirect.com/science/article/abs/pii/S0968432800000664) 明确列出这些因素及其相互依赖。实验装置通常至少报告激发波长、重复频率、脉冲宽度、前向/后向收集物镜 NA 和偏振扫描步进。[跨实验室 SHG 成像比较](https://onlinelibrary.wiley.com/doi/full/10.1002/jbio.202400090) 也将这些参数作为装置间可比性的核心表格项。偏振测量还需要记录角度零点、旋转对象和偏振校准；实际校准会使用分析器和功率计测量入射偏振状态。[偏振 SHG 自动校准](https://pmc.ncbi.nlm.nih.gov/articles/PMC5892897/)

## 建议字段分层

| 情形 | 建议保留并要求 | 说明 |
|---|---|---|
| 所有 SHG | 数据类型、激发波长、样品处功率或仪器设置值及口径、单次采集时间、原始文件 | 功率必须区分样品处实测与仪器设置；不能把二者当同一物理量。 |
| 脉冲激发 | 脉冲宽度、重复频率 | 两者共同决定峰值功率；应校验脉冲宽度小于周期。 |
| 显微成像 | 物镜（从设备目录选择）、收集几何、滤光配置、探测器、像素尺寸或扫描步长 | `objective`、`objective_na` 不应重复录入；NA 随物镜版本冻结。 |
| 偏振扫描 | 入射偏振状态、检偏器状态、旋转对象、角度范围、步长、角度零点/正方向、偏振校准来源 | 当前 `input_polarization` 和 `analyzer_polarization` 是自由文本，难以复用和校验。 |
| 功率扫描 | 扫描轴、起止值、步长或每点值、功率口径 | 不能只记录 `power_scan_coordinates` 文本。 |
| 图像 | 分辨率、像素尺寸、像素驻留时间（若扫描显微镜使用）、曝光时间（若相机使用） | 相机曝光和扫描驻留时间是互斥采集路径，当前同时开放会造成歧义。 |

## 逐项问题

1. **固定配置混入本次条件**：光栅、狭缝、探测器、滤光片、物镜 NA 应在 SHG 仪器目录登记并随版本快照引用；本次表征只选择配置。只有更换光路或临时改变的设置才在条件中记录。
2. **激发功率命名不准确**：`excitation_power_basis` 实际是口径而不是单位；建议拆为 `power_value` + `power_basis`，其中样品处统一 mW，仪器设置保留 `%` 或设备显示单位。
3. **偏振字段过多且互相重叠**：保留结构化的入射状态、检偏状态、旋转对象、角度范围/步长和参考；将两个 legacy 文本字段仅留给历史数据。
4. **收集几何不完整**：反射/透射还不足以表达前向、后向或双向；建议选项为前向、后向、前后同时、其他，并在“其他”时填写说明。
5. **光谱仪字段可能不适用**：SHG 图像和偏振图像未必经过光栅/狭缝；这些字段应仅在 `data_type=spectrum` 或实际光谱采集时显示。
6. **结果与采集混杂**：`intensity_processing`、`accumulation_method` 属于处理/文件元数据，不应与硬件条件并列；处理说明应绑定处理后文件。
7. **“观察到的现象”应保持结果域**：当前 `allowed_property_codes` 仅 observation_note 是合理的，不能在 SHG 表单中加入晶体对称性、层数或材料判定。

## 最小可用方案

先不增加新字段：按 `data_type` 隐藏不适用项；把物镜、探测器、滤光片和收集几何纳入 SHG 设备配置；将偏振扫描改为结构化角度/步长；把功率扫描坐标改为数值序列或范围；保留现有字段名以兼容历史数据。这样能覆盖影响最大的实验变量，且不要求用户填写难以取得的派生量。

## 当前应修改的优先级

- P0：激发波长、功率口径、脉冲参数、原始文件与数据类型的条件校验。
- P1：设备目录化（物镜/探测器/滤光/几何）、偏振扫描结构化、功率扫描结构化。
- P2：清理不适用的光谱/成像字段显示，并把处理字段移到文件处理信息。

本报告只复核设计，尚未修改字段源或业务代码。
