## 1. 设计依据

| 依据 | 支持的判断 | 适用边界 |
|---|---|---|
| [Malard 等，MoS₂ 原子晶体的强 SHG（arXiv 1304.4289，PRB 87, 201401）](https://arxiv.org/abs/1304.4289) | 140 fs、80 MHz、680–1080 nm 可调 Ti:蓝宝石激光；60×/NA 0.75 正入射，背向信号经二向色镜和 SH 波长带通滤光片后由 PMT 检测。功率依赖双对数斜率 2.00±0.02，用于确认信号为 SHG。偏振测量时旋转样品、步长 5°、检偏器与入射偏振平行；**不加检偏器时，总 SH 强度与转角无关**。另用光谱仪+CCD 测量随激发波长变化的 SHG | 用于说明激光、滤光、检测、偏振和功率依赖的物理意义；不代表本组设备相同 |

| [MoSe₂ 单层 SHG 的衬底干涉与应变（Nano Lett. 2024，PMC11487631）](https://pmc.ncbi.nlm.nih.gov/articles/PMC11487631/) | SiO₂ 与 Si₃N₄ 衬底上的 SHG 强度最多相差约 15 倍；干涉贡献与介质种类和厚度有关，其中约 2 倍来自应变 | 说明应显示样品当前载体；不能据此自动修正强度 |

| [Coherent：非线性显微中的峰值功率](https://www.coherent.com/web-resources/white-paper/chameleon-peak-power-wp) | 多光子信号取决于峰值功率，峰值功率由平均功率、脉宽和重复频率决定；显微光路的群延迟色散会展宽脉冲 | 激光器标称脉宽不等于样品处脉宽；不要求用户测量样品处脉宽或自动计算峰值功率 |
| [Waveplate 条目](https://en.wikipedia.org/wiki/Waveplate) | 半波片使线偏振方向旋转 2θ | 这是基础光学关系；因此文件记录的是机械角还是偏振方向角，必须明确 |
| [Optimization of SHG microscopy（Micron，摘要）](https://www.sciencedirect.com/science/article/abs/pii/S0968432800000664) | 超短脉冲、高 NA 物镜、高灵敏度探测器可优化 SHG 成像 | 仅核验摘要 |

生物组织 SHG 文献主要讨论胶原等体材料，前向与后向信号差异及相位匹配问题不能直接套用到二维材料。本报告的判断以二维 TMD 常用做法为主。

## 2. 现状

- 必填 2 项：`data_type`、`excitation_wavelength_nm`。另有 41 项选填，其中 2 项仅供历史读取。在新表单中，按数据类型展开后会显示 24–29 项；打开脉冲、线偏振、固定检偏、其他几何和扫描选项后，会增至 30–35 项。
- 常用区：数据类型、激发波长、功率及口径、单次采集时间、激光输出；偏振扫描时再显示旋转对象。其余项目都在“更多条件”中。
- 设备：SHG 没有结构化目录，只有自由文本固定配置和通用预设。后端对 SHG 拒绝 `instrument_configuration`、`scan_file_id`、`variable_conditions`、`file_intensity_units`。
- 结果：`spectral_peaks` 仅在“光谱”类型下可用，单位为 nm/eV；另有观察说明。未开放取向、层数和对称性判定，这一点符合 §4 冻结决定。
- 详情和导出走通用条件展开路径，没有 SHG 专属逻辑。

## 3. 核心问题：分类

### 3.1 当前分类为什么不成立

| 实际测量 | 现有表达 | 问题 |
|---|---|---|
| 偏振分辨 SHG 成像：逐角度扫描成像 | `data_type` 只能选“图像”或“偏振扫描”之一 | 无论选哪项，另一维度的字段都会被隐藏 |
| 功率依赖测量，每个功率点记录一条光谱 | “光谱”或“功率扫描”只能二选一 | 选“功率扫描”后峰结果不可用；选“光谱”后无法记录逐点功率 |
| 可调谐激光下的激发波长依赖 | 无对应类型 | 只能写入自由文本 |
| 旋转样品、固定平行检偏的点测量 | “偏振扫描”，另可选 `acquisition_kind=series` | 两个字段表达同一件事，且可以互相矛盾 |
| 扫描成像 | “图像”，另可选 `acquisition_kind=single` | 可以保存“单次采集的扫描图像”这类矛盾组合 |

### 3.2 建议分类

复用 PL 已实现的“采集形式 + 变化参数 + 扫描文件”，不另建 SHG 专用机制。

| 维度 | 选项 | 来源 |
|---|---|---|
| 检测配置 | 登记的光谱仪/CCD、PMT/APD、相机配置 | 设备目录选择。探测器类型决定记录形式及时间字段 |
| 采集形式 | 单点 / 空间扫描或成像 / 参数序列 | 本次选择 |
| 变化参数（可多选） | 偏振相关角度、样品转角、功率设置、样品处功率、激发波长（可调谐光源）、时间 | 仅“空间扫描或成像”或“参数序列”时出现，逐点值保存在关联的原始文件中 |

这样，偏振分辨成像记为“空间扫描 + 偏振角”，功率依赖光谱记为“光谱检测配置 + 参数序列 + 功率”。历史 `data_type` 值保留读取，并按以下方式映射：`spectrum` → 光谱检测，`image` → 空间扫描或成像，`polarization_scan` → 参数序列 + 偏振角，`power_scan` → 参数序列 + 功率。

### 3.3 调整后的常规填写顺序

**样品 → 仪器及版本 → 激发光源 → 物镜 → 检测配置 → 功率设置 → 时间、累积或平均次数 → 采集形式 → 偏振（使用时）→ 原始文件。**

| 典型测量 | 需要本次填写或选择 | 设备带入 |
|---|---|---|
| SHG 光谱 | 光谱范围、积分时间、累积次数 | 光栅、狭缝、滤光片、探测器 |
| 偏振分辨测量（点测或成像） | 旋转部件、文件角度含义（旋转波片时）、检偏方式、角度范围和步长、角度参照、扫描文件 | 起偏/检偏部件、设备角度零点 |
| 功率依赖 | 变化参数选“功率”，填写扫描文件列名 | 其余条件固定 |
| 扫描成像 | 像素驻留时间、帧平均次数；图像尺寸和像素尺寸优先由文件提供 | PMT、滤光片 |

配置完整的组内设备和新采集，应要求填写采集形式、功率设置、与检测方式对应的时间和次数；参数序列中声明为变化的量不填写单值。历史或外部仪器保留人工补录路径，不要求补造数据。

## 4. 仪器配置

复用 `capabilities[].configuration.<method>` 目录编辑器、版本快照和预设保护，新增 `configuration.shg`。

| 目录 | 登记内容 | 表征时 |
|---|---|---|
| 激发光源 | 名称、波长（固定值或可调范围）、连续/脉冲、标称脉宽、重复频率、功率控制单位 | 固定值带入；可调谐时填写本次波长。SHG 绝大多数使用脉冲光源；连续光源仍可登记，不在表单中预设 |
| 物镜 | 名称、倍率、NA、介质；显微物镜的 NA 为必填 | 选择后只读显示 |
| 检测配置 | 探测器类型（光谱仪/CCD、PMT/APD、相机）、滤光配置、适用激发波长或波段、收集几何；光谱检测另加光栅和狭缝 | 选择组合。滤光片必须能阻挡基频并通过 SH 波段，更换激发波长时应核对适用范围 |
| 增益 | PMT 电压或增益，以及相机增益；按设备单位登记为固定或可调 | 可调时填写 |
| 偏振部件 | 起偏或入射半波片、检偏器、样品转台、共路半波片是否安装；设备角度零点和正方向 | 使用偏振测量时选择 |
| 校准 | 偏振校准、功率校准，分别记录适用光源、波长和光路 | 关联适用记录；不能用最近一次整机维护代替 |
| 常用预设 | 功率设置、时间、次数、增益、角度步长 | 主动应用，只覆盖对应项；保留结果、观察和来源 |

## 5. 43 个条件字段逐项结论

| # | 当前字段 | 判断与理由 | 建议 |
|---|---|---|---|
| 1 | 数据类型 `data_type` | 将记录形式与变化参数混为单选，见 §3 | 改为由检测配置决定记录形式，偏振和功率改用变化参数表达；历史值按 §3.2 映射 |
| 2 | 激发波长 `excitation_wavelength_nm` | 共振可使强度相差几个数量级（Wang 2015），属于核心条件 | 保留必填；固定光源带入，可调谐光源填写本次值，波长依赖测量作为变化参数。SH 波长 λ/2 可推导，不另填 |
| 3 | 激光功率 `excitation_power_value` | SHG 与功率的平方成正比（Malard），但现在只能保存一种读数 | 同 PL，拆为“功率设置”和选填“样品处功率”，脉冲光源填写平均功率；功率序列中不保存单值 |
| 4 | 功率单位 `excitation_power_basis` | 混淆了读数位置和单位，且缺少仪器 mW 与档位 | 设置单位来自光源登记，样品处功率固定使用 mW |
| 5 | 单次采集时间 `integration_time_s` | 光谱仪为积分时间，PMT 扫描为驻留时间，相机为曝光时间；现在三个字段可同时出现 | 按检测配置只显示一种。光谱检测显示“积分时间（s）”；参数序列表示每点时间 |
| 6 | 物镜规格 `objective` | 文本与第 15 项 NA 可冲突 | 改为选择物镜 |
| 7 | 激光输出 `excitation_mode` | 属于光源固有属性，每次选择容易出错 | 随光源带入，移出常用区 |
| 8 | 脉冲宽度 `pulse_width_fs` | 与峰值功率直接相关；显微光路会展宽脉冲（Coherent） | 在光源登记时必填，名称为“标称脉宽”，支持 fs/ps 输入；后端补充脉宽小于周期的校验（目前仅 PL 有） |
| 9 | 重复频率 `repetition_rate_MHz` | 平均功率相同时，重复频率会改变单脉冲能量 | 在光源登记时必填，支持 MHz/kHz；不自动计算峰值功率 |
| 10 | 入射偏振 `input_polarization`（历史） | 自由文本，已不在新表单中 | 维持历史只读 |
| 11 | 检偏设置 `analyzer_polarization`（历史） | 同上 | 维持历史只读 |
| 12 | 角度零点 `angle_reference` | 与第 26 项含义重复，两者可以填写不同内容；提示中的“不要求填写晶体学取向”没有必要 | 与第 26 项合并为“角度参照”：设备零点随登记带入，只要记录了角度就要求参照；删除该提示 |
| 13 | 旋转对象 `polarization_scan_axis` | 保留有必要，但与第 32 项重复，且缺少共路半波片 | 与第 32 项合并为“旋转部件”：入射半波片/检偏器/样品转台/共路半波片，只显示已登记部件 |
| 14 | 角度范围 `angle_range_deg` | 使用者熟悉，填写容易 | 保留；关联文件后可选填，并校验步长不大于跨度 |
| 15 | 物镜 NA `objective_na` | 倍率不能推出 NA；当前 NA=10 也能通过 | 在显微物镜登记时必填并带入，删除独立可编辑项 |
| 16 | 光栅刻线密度 `grating_lines_per_mm` | 只对光谱检测有意义；现在图像模式下仍可保存 | 仅在光谱检测配置中登记 |
| 17 | 入口狭缝宽度 `slit_width_um` | 同上 | 光谱检测配置中登记固定值，可调时本次填写 |
| 18 | 滤光配置 `filter_configuration` | 决定基频光和双光子发光是否漏入 SH 通道（Malard 使用二向色镜和 SH 带通滤光片） | 在检测配置中登记，并关联适用激发波长；只有更换滤光片时才选择 |
| 19 | 探测器 `detector` | 探测器类型决定记录形式和时间字段 | 在检测配置中登记类型和名称 |
| 20 | 探测器增益 `detector_gain` | PMT 电压或增益使用者熟悉，对信号影响大 | 可调时显示，单位随设备，可为 V、% 或档位 |
| 21 | 收集几何 `collection_geometry` | “背散射”是 Raman 术语 | 改为反射（背向收集）/透射（前向收集）/其他，在设备中登记 |
| 22 | 入射偏振状态 `incident_polarization_state` | 物理分类成立。偏振分辨取向测量使用线偏振；圆偏振 SHG 属于专门实验 | 只提供设备已登记的状态。未安装起偏器不等于非偏振，未知时留空 |
| 23 | 检偏方式 `analyzer_mode` | “随动保持平行/交叉”用词不清；非偏振入射配平行检偏也能通过 | 改为未使用/平行/正交/自定角度，平行和正交仅适用于线偏振。偏振序列时必填，因为不加检偏器时单层 D3h 晶体的总 SH 强度与角度无关（Malard）；但“未使用”仍可保存，例如总强度成像 |
| 24 | 入射偏振角 `incident_polarization_angle_deg` | 旋转入射偏振时仍能保存一个单值，导致矛盾 | 静态测量时填写；入射偏振为变化参数时进入文件，不保存单值 |
| 25 | 检偏器角度 `analyzer_angle_deg` | 选择固定角度却不填角度也能通过 | 自定角度时必填；旋转检偏器时进入文件 |
| 26 | 偏振角参照 `polarization_reference` | 与第 12 项重复，且在非偏振测量中也常驻显示 | 合并入第 12 项，只在有角度时显示 |
| 27 | 其他收集几何 `collection_geometry_other` | 选择“其他”时必须具名，规则合理 | 保留，通常随设备登记 |
| 28 | 采集形式 `acquisition_kind` | 与数据类型重叠，“单次采集”也不准确 | 改为单点/空间扫描或成像/参数序列，与 PL 一致 |
| 29 | 扫描参数 `scan_coordinates` | 自由文本，不关联文件 | 改为关联原始扫描文件（复用 `scan_file_id`），并填写轴、单位和列名 |
| 30 | 强度处理口径 `intensity_processing` | 属于测量级选项，无法区分原始文件与处理后文件；归一化本身是处理 | 改为逐文件强度单位（复用 `file_intensity_units`），归一化记录在处理后文件的说明中 |
| 31 | 累积处理 `accumulation_method` | “分别保存”描述的是文件组织，不是合并方法；SHG 还缺少次数字段 | 保留求和/平均，删除“分别保存”；补充“累积或平均次数”（复用 `accumulations`） |
| 32 | 扫描文件中的角度量 `scan_angle_quantity` | 半波片机械角与偏振方向角相差 2 倍，不记录会使取向分析出错，因此有必要保留 | 合并入第 13 项：旋转半波片时，选择文件角度是“机械角”还是“偏振方向角” |
| 33 | 角度步长 `angle_step_deg` | 使用者熟悉，填写容易（Malard 使用 5°） | 保留，校验不大于跨度 |
| 34 | 逐点功率列 `power_scan_coordinates` | 自由文本，与第 29 项重复 | 删除；把功率设为变化参数，并在扫描文件中填写列名 |

## 7. 已确认的问题及优先次序

| 编号 | 问题 | 顺序 |
|---|---|---|
| SHG-01 | `data_type` 与 `acquisition_kind` 重叠：图像+单次、偏振扫描+序列都能保存；偏振成像、功率光谱序列无法表达 | 第一批，先定分类 |
| SHG-02 | 无设备目录，`instrument_configuration` 被拒绝；物镜文本 NA 与独立 NA 冲突、NA=10 均能通过；图像模式下仍能保存光栅和狭缝 | 第一批，复用目录 |
| SHG-03 | 切换 SHG 仪器或版本时，前端保留全部旧条件（`changeInstrument` 只处理 OM/Raman/PL） | 第一批 |
| SHG-04 | 应用预设会整体替换条件，含 `data_type`；预设不含 `data_type` 时会删除必填项，并清空峰、结果和观察 | 第一批 |
| SHG-05 | 预设不限字段：数据类型、样品处理、备注、样品处功率、光斑在前后端均能通过 | 第一批 |
| SHG-06 | 功率设置与样品处测值只能二选一；功率扫描时仍可保存单值功率 | 第二批 |
| SHG-07 | 偏振规则缺失：两个参照字段可冲突；样品转台与波片角度量、旋转检偏器与未使用检偏器可同时出现；旋转入射偏振时仍保存单值角度；非偏振配随动平行、固定角无角度、有角度无参照、步长大于跨度均能通过 | 第二批 |
| SHG-08 | 扫描文件和变化参数仅对 Raman/PL 开放；空间扫描、序列、偏振扫描、功率扫描在无文件、无参数时均可保存 | 第二批 |
| SHG-09 | 脉冲模式可缺少脉宽和频率；20 ns 脉宽配 80 MHz 也能通过，因为脉宽小于周期的检查仅对 PL 生效 | 第二批 |
| SHG-10 | 图像模式下积分、曝光、驻留三个时间可同时保存；缺少累积次数；累积方式含“分别保存” | 第二批 |
| SHG-11 | 无光谱范围；强度单位不能按文件记录 | 第二批 |
| SHG-12 | 未显示当前载体；校准仅取整机最近记录 | 第三批 |
| SHG-13 | 除 OM/Raman/PL 目录键外，capability `configuration` 中的未知键（如 `shg`）被静默接受 | 第三批，随目录实现一并收紧 |
| SHG-14 | 文案：“不要求填写晶体学取向”；“保留样品处实测或仪器设置口径”；占位符“参数变化不共用一个数值” | 随改动删除 |
| SHG-15 | 原生文件（PMT 图像栈、光谱文件）尚未解析 | 取得真实机型和文件后实施 |

需要组内确认的实际情况（不影响先实施 SHG-01～05）：本组 SHG 设备使用 PMT 扫描、光谱仪还是相机检测；样品处功率通常在物镜后测，还是在物镜前测。若在物镜前测，应另设测量位置选项，不能直接记为样品处功率。
