## 走查中发现并修复的问题

| 严重度 | 问题 | 修复结论 |
|---|---|---|
| 高 | 新建炉次仍展示完整工艺字段，并要求用户手填炉次编号。 | 新建页缩减为时间、方法、实验人，后端自动编号；新增组件和表单测试。 |
| 中 | “下拉+其他”被当成普通下拉，成员姓名和自由化学式无法自然录入。 | 新增统一的“下拉+其他”控件，实体库和炉次表单共用；规范选项仍提交原值。 |
| 中 | 锁定成功后样品查询未失效，页面可能短暂显示“尚无样品”。 | 状态转换统一失效炉次、样品和审计查询，并增加测试。 |
| 中 | 中英文资源齐全但页头没有语言切换入口。 | 新增可见、可访问的页头语言按钮和交互测试。 |
| 低 | 英文附件控件的可访问名称仍显示中文规范方法“光镜”。 | 仅本地化展示名为 “Optical microscopy”，上传载荷仍保留规范值。 |
| 低 | “下拉+其他”的领域标记散落在 UI 文件，触发硬编码文案门禁。 | 将领域判定集中到纯逻辑模块；硬编码门禁恢复通过。 |
| 低 | 实体库“下拉+其他”的标签和错误信息未正确关联选择框。 | 关联 label、帮助与错误 ID，向选择框和其他值输入框传递 `aria-invalid`/`aria-describedby`；独立复审确认关闭。 |
