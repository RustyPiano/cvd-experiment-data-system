# CVD 浏览器 E2E 走查工单

> 当前操作检查单。炉次优先工作流重构完成后，按新界面同步更新步骤再执行。

仓库:当前目录。**只验证,不修改任何仓库文件、不 git commit**;发现问题记录到报告,不要顺手修。

## 环境自建(你自己起服务,结束后自己清理)

1. 后端:一次性 SQLite 库(如 /tmp/cvd-f6-e2e.sqlite3)+ 临时 FILE_STORAGE_ROOT;先 `uv run alembic upgrade head`,建 admin 账号(create_admin 或 create_user,交互密码你自己定),再起 `uv run fastapi dev app/main.py --port 8000`(后台)。
2. 前端:`cd frontend-next && bun run dev`(端口 3000,Vite 代理 /api)。
3. 全部验证完成后杀掉两个 dev 进程、删临时库/存储目录。

## 走查链路(内置浏览器,1280×720,关键节点截图到 /tmp/cvd-f6-*.png)

1. 登录 → `/experiments` 单轨列表(侧栏无 v1 项)。
2. 实体库:建 MaterialLot、Setup、Instrument 各一(含锁版:追加一个版本)。
3. 新建炉次:完整录入 §1–§7,**重点验证上一轮修复项**——复合输入字段(气体流量填 `80`+选 `MFC`、压力体系选 `常压(APCVD)`+填数值)保存后回读两部分都在;目标产物化学式保存后列表"材料体系"同步显示(非 —)。
4. submit(缺 R0 时观察 422 结构化缺失清单展示)→ 补齐 → submit 成功 → lock。
5. **锁定语义甲**:锁定横幅显示"工艺已锁定,结果可继续补录";工艺模块只读;**结果区仍可操作**——建样 → 建表征记录 → **给表征记录上传附件(F4 新功能)** → 建实测产物(挂该表征记录)→ 观察列表"结果缺失"标记消失。
6. 删实测产物→尝试删表征记录(应先被 409 拦截若附件在,按提示删附件后成功)→ 观察"结果缺失"恢复。
7. admin unlock → 回 submitted → 工艺可再编辑。
8. 样品详情页:打开建的样品,确认读 v2 炉次信息与关联文件正常。
9. Console 检查:全程无 React 警告/未捕获错误(Node DEP 提示忽略)。

报告:逐步结果表(通过/失败+现象)、发现的问题清单(严重度+复现步骤+根因猜测,**不修**)、截图路径清单、控制台异常清单。最终一行:PASS 或 FAIL(任一功能性问题=FAIL)。
