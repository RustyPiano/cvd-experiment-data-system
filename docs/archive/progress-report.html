01 项目架构

⚙️ 后端 Backend

FastAPI · SQLAlchemy · Alembic · PostgreSQL
  • 模块化 payload：实验由 10 个模块组成（basic_info、environment、precheck、precursors、substrates、furnace_program、gas_program、process_observation、characterization、result_summary）
  • JSONB 存储：payload_json 落 JSONB，Pydantic 做运行时校验
  • 受控词表：controlled_vocabularies，本轮新增分组列
  • 版本化：实验草稿 / 提交 / 版本快照

🖥️ 前端 Frontend

TanStack Router/Query · shadcn/ui · Tailwind v4
  • 类型安全：由后端 OpenAPI 生成 openapi.d.ts（npm run gen:api）
  • 模块编辑器：每个模块一个 section 组件 + 序列化层 editor-types
  • 词表下拉：VocabularyCombobox，本轮将做分组渲染
  • 设计系统：克制的现代 + 科研气质，token 化

「三套真相」与定调

● 运行时校验权威
Pydantic schemas

module_payload 的实际校验者。不重写，作为唯一真相源。

● 可发布规范层
FieldDefinition 表

描述单位 / 类型 / 词表 / 标签，用于表单渲染与对外规范产物。

● 存储数据
payload_json (JSONB)

真正落库的数据 blob。

定调：三者会漂移 → M1 用一致性守卫测试把它们锁在一起；后续新增字段无法再悄悄制造漂移。
