🧪

CVD 实验数据采集系统

面向课题组的标准化 · 结构化 · 可挖掘的 CVD 二维材料工艺数据库

把全组的 CVD 实验,变成一套人人用同一套词、结构一致、不会丢的数据库 —— 既能日常记录,也能横向比较、检索复用,长期沉淀为可做数据挖掘的 AI-Ready 资产。

📊 10 个数据模块 🏷️ 68 个标准字段 📖 受控词表统一选项 🔒 状态机 + 版本快照 + 审计 🌐 已上线 cvd.rustypiano.com
01

为什么需要这个系统Why

现状的痛点

  • ✕数据散在各人的本子 / Excel / 微信里,人一走就断档
  • ✕同一材料、同一表征,写法五花八门 → 没法横向比较与检索
  • ✕失败实验往往不记录,别人反复踩同一个坑
  • ✕装置/参数版本说不清,"这炉到底用的哪套条件"无法追溯

系统带来的

  • ✓统一字段 + 受控词表,数据天然可比、可检索
  • ✓按模块结构化录入,自动保存、不会丢
  • ✓成功与失败都记(含失败模式词表),沉淀经验
  • ✓提交即版本快照 + 全程审计,装置以快照冻结可追溯
标准化
同一套词表与字段,全组数据口径一致,可横向比对。
结构化
10 模块 / 68 字段,机器可读,一键导出 JSON·Excel。
可追溯
状态机 + 版本快照 + 审计日志,谁改了什么一清二楚。
可挖掘
长期沉淀为 AI-Ready 数据集,支撑数据挖掘与论文。

📖 题眼 · 受控词表 = 标准化的核心
大量字段的选项来自统一维护的"受控词表",大家填的是同一套词,数据才可比、可检索、可挖掘 —— 这正是"标准数据库"与"每人一个 Excel"的本质区别。词表由管理员统一维护、可随时扩充。
material_system 材料体系 precursor_method 制备方法 substrate_type 基底类型 gas_label 气体 characterization_method 表征方法 quality_label 质量标签 failure_mode 失败模式 …
🧰 Setup 库 / 装置快照
装置示意图 + 方法文本 + 参考文献;一键引用并冻结为快照（带哈希）,保证"这炉用哪套装置"可追溯。
🔬 样品 Samples
基底与产物自动成为可追踪样品,有独立编号、角色、存放位置。
📎 文件 Files
Raman/SEM 等原始文件直接挂在实验或样品下,统一管理。
🛠️ 词表 / 字段字典
管理员维护受控词表与字段定义,字段字典可自动生成（本页即由其而来）。
04

使用流程Workflow

1
登录
浏览器打开网址,账号登录,落到实验列表
2
新建
空白创建 / 复制最近一条 / 搜索历史派生
3
填写
按模块录入,带 ★ 必填,改即自动保存
4
提交
系统校验,通过后自动存版本快照
5
锁定
定稿,只读;管理员可解锁更正
6
导出
逐条导出 JSON / Excel

🔄 记录状态机

草稿 →提交 已提交 →锁定 已锁定
已作废 ↞ 作废（已提交记录） · 草稿可直接删除 · 锁定可由管理员解锁

提交即生成版本快照;复制 / 派生历史实验可一键起步同类工艺,改几个数即可。

👥 两类角色

角色能做什么
组员
member		 新建 / 填写 / 提交自己的实验;可查看他人已提交·已锁定的记录;导出、上传表征文件、管理自己的样品。
管理员
admin		 组员的全部能力 + 数据看板（全员记录数·状态·停滞草稿·缺装置·录入趋势,点成员可单看）;锁定 / 解锁;维护受控词表与字段字典、Setup 库。
